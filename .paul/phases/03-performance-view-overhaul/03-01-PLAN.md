# Plan 03-01: Performance View Overhaul

## Goal

Make the live performance setlist view the essential "at-a-glance" experience for the band on tablets and phones. Remove the tablet sidebar toolbar regression, redesign SetlistRow for live glanceability (keys prominent, clear song order), and verify no other visual regressions from v1.5.

## Design System (from UI/UX Pro Max)

- **Palette:** Dark-first OKLCH indigo (bg `#0F0F23`, text `#F8FAFC`, brand indigo `#4338CA`)
- **Fonts:** Righteous (headings) / Poppins (body) — already in use
- **Key effects:** Bold hover (color shift), smooth transitions 200-300ms
- **Anti-patterns to avoid:** Text-heavy rows, flat design without depth

### Task 2: Redesign SetlistRow for live performance glanceability

**Files:**
- `src/components/performance/SetlistRow.tsx`

**Current layout:** `[Title (flex-1)] [Key badge] [BPM] [Lead]` — key is a small badge, easy to miss.

**New layout — optimized for glanceability:**

```
┌──────────────────────────────────────────────────┐
│  ┌────┐                                          │
│  │ Am │  Song Title                    120 BPM   │
│  └────┘  Lead: Randy                             │
│                                                  │
│  ┌─────────────────────────────────────────────┐ │
│  │──── Section Header ────                     │ │
│  └─────────────────────────────────────────────┘ │
│                                                  │
│  ┌────┐                                          │
│  │ G  │  Another Song Title             80 BPM   │
│  └────┘                                          │
│                                                  │
│        Non-Song Item (dimmed)                    │
└──────────────────────────────────────────────────┘
```

**Design decisions:**
- Key badge moves to the LEFT of the title — most important info for musicians, visible at a glance
- Key badge gets larger: `text-base font-bold px-2.5 py-1.5 min-w-[3rem] text-center`
- Two-line layout for songs: Title + BPM on row 1, Lead musician on row 2 (if present)
- Songs without keys still align — title starts at same position via consistent left margin
- Current position: stronger highlight with `bg-brand/20 border-l-4 border-brand`
- Active/tappable rows: `active:scale-[0.98]` for tactile feedback on touch
- No emoji icons — only SVG via Lucide

**Accessibility:**
- Touch targets remain ≥ 44px (py-3 on a 16px base = ~48px row height)
- Color contrast 4.5:1+ maintained (brand on dark bg)
- Focus rings preserved on interactive rows
