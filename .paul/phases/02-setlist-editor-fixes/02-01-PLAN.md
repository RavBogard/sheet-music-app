Make the musical key prominently visible in the setlist editor collapsed row, and update the default monitor bus configuration from 4 to 5 buses.

Note: "Fix auto-key detection on chart assignment" was already completed in commit c6375f4 (v1.3.1). That requirement should be marked validated.

- Key displayed prominently in SongRow collapsed view (larger, high-contrast badge)
- Default monitor config uses 5 buses
- Wizard placeholder updated to match
