<objective>
## Goal
Fix setlist permissions so admin/band_leader users can delete, duplicate, clone, and edit any public setlist — not just their own. Also fix the print pipeline: include non-song items on the cover page outline, and show the setlist's `rabbi` field as the service leader instead of the creator.

## Purpose
Rabbi Daniel creates most setlists but needs any band leader to manage them. The printed outline should show the full order of service (including readings/prayers) and attribute leadership to the rabbi leading the service.

## Output
- Delete/duplicate/clone/edit permissions broadened for admin + band_leader
- Print cover page includes non-song items (readings, prayers, transitions)
- Print cover page shows "Led by: {rabbi}" when the rabbi field is set
</objective>
