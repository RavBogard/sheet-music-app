<objective>
## Goal
Add tablet landscape layout for performance mode, mobile zoom indicator, and skip-to-main-content keyboard navigation link.

## Purpose
Musicians use tablets (iPads) in landscape during services. The current layout jumps from mobile 2-row to desktop 1-row at `lg:` (1024px) with no tablet-optimized view. Adding a side-by-side PDF+toolbar layout for tablets, mobile zoom display, and a skip link improves the live performance experience and WCAG compliance.

## Output
Modified performance layout with tablet breakpoint, zoom indicator on mobile toolbar, and skip-to-main-content link in root layout.

## Already Satisfied (no work needed)
- prefers-reduced-motion: Already in globals.css + TempoFlash.tsx
- Modal focus trapping: Radix Dialog handles WCAG 2.4.3
- LibraryFileRow colors: Already uses brand palette (bg-brand/10, text-brand)
- Ghost button hover: Already uses hover:bg-accent + dark:hover:bg-secondary/30
</objective>
