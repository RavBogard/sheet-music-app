<objective>
## Goal
Optimize the tablet performance experience for iPad portrait mode (768x1024). Increase all touch targets to 44px+ minimum, add a tablet-responsive `md:` breakpoint to the toolbar, recover wasted PDF screen space, fix swipe-while-zoomed, extend auto-hide timeout, and widen song title display.

## Purpose
Musicians use iPads on music stands during live worship services. The toolbar is currently optimized for phone (cramped) or desktop (spacious) but has no tablet layout at 768px. Zoom buttons are 28px — far below the 44px minimum for reliable touch. This phase makes the most-used view in the app actually work well on its most-used device.

## Output
Modified performance components with tablet-responsive toolbar, proper touch targets, and optimized PDF viewing area.
</objective>

## AC-1: Zoom Touch Targets Meet 44px Minimum
```gherkin
Given the performance toolbar is visible on a 768px-wide tablet
When a musician taps the zoom in or zoom out button
Then the button hit area is at least 44x44px (h-11 w-11) in compact mode
And the zoom action registers reliably without mis-taps
```

## AC-2: Tablet Toolbar Layout at md: Breakpoint
```gherkin
Given a tablet in portrait mode (768px width)
When the performance toolbar renders
Then it uses a tablet-optimized layout (not the cramped phone layout)
And all toolbar controls are spaced with adequate touch gaps
And the song title is not truncated to unreadable length
```

## AC-3: PDF Viewing Area Maximized
```gherkin
Given a musician is viewing a chart PDF on tablet
When the toolbar is hidden (auto-hide or tap toggle)
Then no bottom padding wastes screen space (pb-28 removed)
And the PDF content fills the available viewport
```

## AC-4: Swipe Navigation Works When Slightly Zoomed
```gherkin
Given a musician has zoomed to 1.1x-1.5x to read fine print
When they perform a horizontal swipe gesture
Then the app navigates to the next/previous chart
And vertical scroll/pan still works normally for the zoomed content
```

## AC-5: Auto-Hide Timeout Extended for Performance
```gherkin
Given the toolbar is visible during performance
When no popover is open and no interaction occurs
Then the toolbar auto-hides after 15 seconds (not 8)
And tapping content toggles visibility
```

## AC-6: Song Title Readable on Tablet
```gherkin
Given a song with a long title (e.g., "Mi Chamocha / Who Is Like You")
When displayed in the PerformanceStatusStrip on a 768px tablet
Then the title truncates at max-w-[300px] (not 200px)
And the text is readable at music-stand distance (2-3 feet)
```

       - Tablet layout: `md:` (768-1023px) — single row like desktop but slightly more compact
       - Desktop layout: `lg:` (1024px+) — keep as-is

       - Right: Sync + Monitor + Metronome + Transposer
       - All controls use non-compact sizes (h-10/h-11)

    Avoid: Changing desktop (lg:) layout. Avoid landscape-specific media queries.
