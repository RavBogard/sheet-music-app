<objective>
## Goal
Mount the LeaderConsole component on the performance page so leaders/admins can start Live Mode and step through the service. Once live mode is active, swap buttons (already wired) become visible to users with canLiveSwap permission.

## Purpose
The entire v3.0 Live Setlist Sync feature (LeaderConsole, SwapButton, SwapBottomSheet, SwapToast, /live/[id] receiver) is built but LeaderConsole was never mounted — so nobody can actually start live mode. This plan connects the final wire.

## Output
- LeaderConsole rendered on performance page for leaders/admins
- Live mode can be started, stepped through, and ended
- Swap buttons appear automatically for eligible users during live mode
- /live/[id] receiver page works end-to-end
</objective>
