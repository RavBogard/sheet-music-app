These modules handle AI chord detection, key estimation, and metadata enrichment — core features of the music library. Tests ensure the text-merging algorithm, chord filtering, error handling, and Gemini integration work correctly and don't regress.

## AC-1: Gemini Module Tests
```gherkin
Given gemini.ts is imported in a test environment
When GOOGLE_GENERATIVE_AI_API_KEY is missing
Then getGenAI() throws a descriptive error

Given a valid API key is set
When geminiFlash() or geminiProVision() is called
Then a GenerativeModel instance is returned with the correct model name
```

## AC-2: PDF Chord Extractor Tests
```gherkin
Given a mocked PDF with text items at known positions
When extractChordsFromPdf is called
Then chords are correctly identified, merged, and positioned

Given text items split across multiple PDF text objects (e.g., "F" + "#" + "m")
When the two-pass merge algorithm runs
Then they are reassembled into "F#m"

Given a PDF with no chord-like text
When extraction runs
Then result contains 0 totalChords with correct page dimensions

Given a multi-page PDF
When extractChordsFromPdf is called
Then each page's chords are returned separately with correct page numbers
```

## AC-3: Key Detection Tests
```gherkin
Given a valid fileId pointing to a PDF with chords on page 1
When detectKeyFromPdf is called
Then the estimated key is returned (e.g., "G", "Am")

Given a fileId for a non-PDF file
When detectKeyFromPdf is called
Then null is returned without error

Given a fileId for a file that doesn't exist
When detectKeyFromPdf is called
Then null is returned and a warning is logged

Given a PDF with no detectable chords
When detectKeyFromPdf is called
Then null is returned
```

## AC-4: Enrichment Engine Tests
```gherkin
Given a valid fileId and Gemini returns valid JSON metadata
When enrichFile is called
Then metadata is parsed and saved to Firestore library_index

Given Gemini returns markdown-wrapped JSON (```json ... ```)
When enrichFile parses the response
Then markdown fences are stripped and JSON is parsed correctly

Given Gemini returns invalid/unparseable text
When enrichFile is called
Then an error is thrown with "AI returned invalid JSON"

Given a fileId for a non-existent file
When enrichFile is called
Then an error is thrown with "File not found"
```
