scoped `/perform` service worker + IndexedDB chart cache were re-introduced
2026-05-28, and the live sweep confirmed open-chart-offline + offline next/prev

use" indicator rendering. So v11.6-03 is NOT "re-introduce offline" — it is
"verify the working path + decide which narrow residual gaps to close." The two
Camp Sabra sets are text/plain (the highest-leverage off-site surface); the camp
may be the venue that breaks the "venue has wifi" assumption. We must not churn
the working SW/IDB path, and we must not trust the report's line numbers blindly
— verify against deployed code first (the report is a snapshot; code is truth).
