<context>
@.paul/phases/v43-01-recursive-research/FINDINGS.md

**B03** Monitor-client debounce race: snapshot + disconnect can interleave so `forwardSnapshot(null)` fires after teardown. `src/lib/firestore-monitor-client.ts:122-132`.
**B04** `use-setlist-logic` `loadLibraryMeta` closes over `file.id` in an async loop; tracks array may have shifted by resolution time, stamping the key onto the wrong row. `:586-594`.
**B05** `DashboardClient` subscription unsub gated on `setlistService` truthiness; if auth flips to null before the effect runs, no unsubscribe. `:110-122`.
**B06** `swapTrack` transaction doesn't assert `remote.tracks` is an array — corrupted doc raises an uncaught error that aborts silently without `StaleWriteError`. `src/lib/setlist-firebase.ts:288-316`.
</context>

<acceptance_criteria>
- **B03**: add `_disconnected` flag; `forwardSnapshot` becomes no-op after disconnect. Debounce-timer callback also checks the flag.
- **B04**: bind `file.id` into a local const before the async resolution; find-row by index at resolve time (don't rely on closure).
- **B05**: unsub runs unconditionally in the effect cleanup regardless of `setlistService` state.
- **B06**: swapTrack validates `Array.isArray(remote.tracks)` before indexing; throws `StaleWriteError` (or a specific CorruptedDocError) with context instead of a generic array-access crash.
- No regressions: full suite green.
</acceptance_criteria>
