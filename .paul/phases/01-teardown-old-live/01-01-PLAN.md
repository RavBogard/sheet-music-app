<objective>
## Goal
Remove the entire old live mode system: components, pages, hooks, lib functions, API routes, types, admin UI, and Firestore rules. Clean teardown with no replacement — Phase 3 will build the new inline swap.

## Purpose
The old live system (v3.0-v3.4) was over-engineered: separate live mode, presence tracking, song groups, receiver page, step-through navigation. User wants simple inline editing that syncs to everyone via existing Firestore real-time. All this infrastructure must go first.

## Output
- All live mode files deleted
- All references cleaned from remaining files
- Firestore rules simplified
- Build passes, tests pass
</objective>
