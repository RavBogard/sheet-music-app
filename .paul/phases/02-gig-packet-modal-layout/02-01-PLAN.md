<objective>
## Goal
Fix the PrintModal so the configuration form is immediately visible when opened, with no excessive empty space above it.

## Purpose
Users report having to scroll way down to reach the gig packet configuration controls. The modal centers vertically with generous padding and a tall footer, cramping the content area — especially on mobile/tablet. This has been a recurring complaint.

## Output
- PrintModal with content immediately visible on open
- No excessive whitespace above the form
- Works well on both mobile and desktop
</objective>

  <action>
    Make the following targeted CSS changes to the PrintModal:

    1. **Outer container:** Change `items-center` to `items-start` on mobile, keep centered on desktop:
       - Replace `flex items-center justify-center` with `flex items-start sm:items-center justify-center`
       - Change `p-4` to `pt-8 sm:pt-4 px-4 pb-4` (push modal near top on mobile with slight margin)

    2. **Content area:** Tighten padding and gaps:
       - Change `p-6 space-y-5` to `p-4 space-y-3`

    3. **Modal container:** Allow more vertical space on mobile:
       - Change `max-h-[90vh]` to `max-h-[95vh] sm:max-h-[90vh]`

    These 3 changes address all contributors to the empty space issue:
    - Modal no longer centered-vertically on mobile (starts near top)
    - Content padding reduced from 24px to 16px
    - Content gaps reduced from 20px to 12px
    - More vertical space available on mobile

    Avoid:
    - Changing the footer layout or button structure
    - Changing the PrintModeSelector or PrintStats components
    - Adding any responsive breakpoints beyond sm:
    - Restructuring the modal's flex layout
  </action>
