# Phase v11.2-02 Plan 01: publish-audience org scoping (BUG-9) Summary

**Closed a CONFIRMED cross-tenant notification leak: `publish_setlist`/`preview_publish` derived recipients from the ENTIRE `users` collection, so a Brothers Lazaroff publish would have notified CRC's roster (push/email/SMS). Recipients are now scoped to the setlist's org via the v11-05-02 roster pattern, plus a caller-org wall the publish path was missing.**
