<objective>
## Goal
Test all server-side data layer functions: getServerUser, serializeSetlist, getServerCongregationConfig (server-auth), 4 setlist query functions (server-setlists), and getServerLibrary with pagination (server-library).

## Purpose
Server-side functions are the SSR data backbone — they power the dashboard, schedule page, and library page load. Untested Firestore queries can silently break when schemas evolve in future phases. These are pure data functions with no UI, making them ideal test targets.

## Output
- `src/lib/__tests__/server-auth.test.ts` — tests for getServerUser, serializeSetlist, getServerCongregationConfig
- `src/lib/__tests__/server-setlists.test.ts` — tests for all 4 setlist query functions
- `src/lib/__tests__/server-library.test.ts` — tests for getServerLibrary (including pagination and malformed docs)
</objective>
