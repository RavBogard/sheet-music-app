<objective>
## Goal
Test all client-side Firebase data layer functions: users-firebase (profile CRUD, subscriptions, role updates) and scheduling-firebase (real-time subscriptions, API wrappers, calendar token generation).

## Purpose
These functions are the client-side data backbone — they power auth flows, user profiles, scheduling views, and assignment management. Client-side Firestore subscriptions (onSnapshot) and API wrapper functions need tests to catch regressions when models evolve.

## Output
- `src/lib/__tests__/users-firebase.test.ts` — tests for ensureUserProfile, subscribeToUserProfile, subscribeToAllUsers, updateUserRole, updateUserDisplayName, markWelcomeModalViewed
- `src/lib/__tests__/scheduling-firebase.test.ts` — tests for 4 subscription functions, 3 API wrappers, generateCalendarFeedToken
</objective>

    2. Throws when not authenticated (no currentUser)

    2. No-ops when db is empty
