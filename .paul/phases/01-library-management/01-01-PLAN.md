<objective>
## Goal
Add three missing library management capabilities: (1) rename song titles in the library, (2) remove/unlink a chart from a setlist track, and (3) view and restore archived songs.

## Purpose
Users lost songs like "Olam Chesed" to the duplicate scanner with no way to get them back. Song titles are locked to filenames with no way to correct them. And there's no way to unlink a chart from a track without deleting the entire track.

## Output
- Library songs can be renamed via context menu
- Setlist tracks can have their chart unlinked (keeping the track row)
- Archived songs visible and restorable from the Library tab on the manage page
</objective>

<acceptance_criteria>

## AC-1: Rename Song Title in Library
```gherkin
Given a song in the library with a title derived from its filename
When an admin long-presses or uses the context menu and selects "Rename"
Then a dialog appears with the current title pre-filled
And the user can type a new title and save it
And the new title persists in Firestore library_index and displays immediately
```

## AC-2: Unlink Chart from Setlist Track
```gherkin
Given a setlist track with a linked chart (fileId set)
When the user expands the track in edit mode and clicks "Unlink Chart"
Then the track's fileId and fileName are cleared
And the track row remains in the setlist (not deleted)
And the track title is preserved
```

## AC-3: View and Restore Archived Songs
```gherkin
Given songs have been archived (status='archived' in Firestore)
When an admin navigates to the manage page Library tab
Then they see an "Archived" section or toggle showing archived songs
And each archived song has a "Restore" button
And clicking Restore calls the archive API with archive=false
And the song reappears in the main library list
```
