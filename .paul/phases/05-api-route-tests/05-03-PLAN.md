## AC-1: list route returns paginated library files
```gherkin
Given a GET to /api/library/list
When library_index documents exist in Firestore
Then it returns files array with id, name, mimeType, status
  and returns nextCursor when more pages available
  and respects limit parameter (default 200, max 500)
```

## AC-2: list route supports filtering modes
```gherkin
Given a GET to /api/library/list with query params
When status=archived is specified
Then only archived files are returned (with archivedAt, archivedBy)
  and active files include status field but exclude archived
```

## AC-3: rename route updates displayName
```gherkin
Given a PATCH to /api/library/rename with { fileId, displayName }
When the file exists and user is band_leader
Then displayName is updated in Firestore
  and modifiedTime is set
  and response returns { success: true, displayName }
  and returns 404 for missing files
```

## AC-4: archive route toggles soft-delete status
```gherkin
Given a PATCH to /api/library/archive with { fileId, archive }
When the file exists and user is band_leader
Then archive=true sets status to 'archived' with archivedBy and archivedAt
  and archive=false restores to 'active' with null archivedBy/archivedAt
  and returns 404 for missing files
```
