<objective>
## Goal
Make SwapPicker fast and keyboard-driven on stage: Enter picks the top result, Esc closes, arrow keys move selection, search starts empty (not pre-filled with the song you're replacing), and iOS reliably autofocuses the input.

## Purpose
The swap flow is the #1 stage interaction during service. Today it pre-fills the search with the song being *replaced*, forcing the leader to clear it before typing the replacement. There are no keyboard bindings, so iPad + Bluetooth keyboard users must tap. The 100ms autofocus hack already exists but iOS Safari still occasionally drops focus. These friction points compound under service-day pressure.

## Output
Single-file change to `src/components/performance/SwapPicker.tsx`. No new dependencies. No API surface changes (props unchanged).
</objective>

    On the search input's `onKeyDown`:
      - `Escape` → e.preventDefault(); onClose().
      - `ArrowDown` → e.preventDefault(); setSelectedIndex((i) => (i + 1) % results.length) (guard empty).
      - `ArrowUp` → e.preventDefault(); setSelectedIndex((i) => (i - 1 + results.length) % results.length).

    Scroll selected row into view with `ref` + `scrollIntoView({ block: "nearest" })` when selectedIndex changes.
    Avoid: binding keydown to `window` — input-scoped handler is enough and avoids collisions with the parent perform page's shortcuts.
    Avoid: swallowing keys when results is empty (Esc and typing must still work).
  </action>

<task type="auto">
  <name>Task 3: Harden iOS autofocus</name>
  <files>src/components/performance/SwapPicker.tsx</files>
  <action>
    Keep the existing 100ms `setTimeout` but also call `inputRef.current?.focus({ preventScroll: true })` inside a `requestAnimationFrame` chained after the timeout fires — two-step focus is the known iOS Safari workaround when the element is inside an animated container.
    Ensure the input is rendered (not conditionally hidden) before the timer fires — current code already does this.
    Do not add `autoFocus` prop — it races with the animation and is what the setTimeout hack exists to bypass.
