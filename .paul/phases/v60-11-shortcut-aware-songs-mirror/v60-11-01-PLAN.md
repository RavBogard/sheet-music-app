<objective>
## Goal
Close the gap between `library_index` (498 docs) and `songs/*` (364 docs) so the chart-binder picker shows the ~134 Google Drive shortcut entries (e.g. "Lechu Goldman") that the v54-01-01 MIME-filter bootstrap intentionally excluded — by (a) extending the cron `syncLibraryIndex` writer to mirror every library_index entry to `songs/*` regardless of MIME, (b) running a one-off backfill of the 134 historical shortcut docs, and (c) folding in the latent subscribe.ts self-heal omission from v60-09 (missing `recoverFromFirestoreShutdown` call).

## Purpose
Closes UAT Issue 1 from the 2026-05-13 v60-09 push: Daniel reported "Lechu Goldman" and similar songs missing from the chart-binder picker despite being visible in the Library section. Production diagnostic (admin SDK reads via `scripts/diag-lechu-goldman.ts`) confirmed the 134-doc gap is shortcuts excluded by the bootstrap's `CHART_MIME_TYPES` filter. The v60-09 listener works correctly — it just has nothing to deliver because `songs/{shortcutId}` was never written.

Also fixes latent Issue 3: `subscribe.ts:101-103` error handler doesn't call `recoverFromFirestoreShutdown` like the 5 sibling listeners (`alert-store.ts`, `firestore-monitor-client.ts`, `use-monitor-connection.ts`, `use-safe-firestore-sync.ts`, `notification-store.ts`). After a service-worker deploy, if the songs listener dies with "Firestore shutting down" it stays dead silently — users must manually reload.

This is the v6.0 milestone-close gate — once shipped + Daniel-loop UAT clears (Fri PM / Sat AM worship cycle), v6.0 can close.

## Output
- `subscribeSongsLibrary` self-heals after Firestore shutdown via SW deploy.
- Every Drive entity in `library_index` (PDF, MusicXML, shortcut, audio, doc, folder — all of them) has a matching `songs/{id}` doc going forward via `syncLibraryIndex`.
- 134 historical shortcut docs backfilled into `songs/*` with `status: 'active'`.

       ```ts
         const songsBatch = db.batch()
         const now = new Date().toISOString()

         for (const file of chunk) {
           const docRef = db.collection('library_index').doc(file.id)

           // v60-11-01: mirror to songs/* with NO MIME filter and NO status field.

           }
           // ... existing stats tracking unchanged ...
         }

         // Commit both batches in parallel. allSettled → songs/* failure is non-fatal.
         await Promise.allSettled([batch.commit(), songsBatch.commit()])
       }
       ```

       Helper:
       ```ts
       function buildSongsPayload(fileId: string, rawName: string, existsInLibrary: boolean): Record<string, unknown> {
         // Match bootstrap-songs.ts:142 verbatim — title is raw library_index.name with NO extension stripping.
         // The 364 existing bootstrap-written docs carry "Adon Olam.pdf" form; new mirrors must match
         // or the picker will show mixed shapes side-by-side.
         const title = rawName  // already trimmed by caller
         const payload: Record<string, unknown> = {
           id: fileId,
           title,
           normalizedTitle: title.toLowerCase(),
           fileId,
         }
         // createdAt only on first write (when this file is new to library_index).
         // .set({merge: true}) preserves existing createdAt on subsequent ticks.
         if (!existsInLibrary) {
           payload.createdAt = Date.now()
         }
         // NO status field — owned by /api/library/archive. .set({merge: true}) preserves it.
         return payload
       }
       ```
