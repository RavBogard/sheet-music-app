### Auto-fixed Issues

**1. [test-harness] `vi.mock` of `@/lib/google-drive` wiped the real `driveSourceIsConvertible`**
- **Found during:** Task 3 (emulator tests)
- **Issue:** The existing mock replaced the whole module with only a `DriveClient` class. Once `importChartFromDrive` imported the new pure classifier from the same module, every existing `import_chart_from_drive` test would have thrown `driveSourceIsConvertible is not a function`.
- **Fix:** Switched the mock factory to `async (importActual) => ({ ...actual, DriveClient: <stub> })`, preserving the real classifier while still stubbing the network surface; added `fetchAsPdf` to the stub + `mockReset()` in `beforeEach`.
- **Files:** `mcp-chart-upload.emulator.test.ts`
- **Verification:** Full suite 58/58 green (would have been red without this).
- **Commit:** pending phase-close

Two pre-existing tests asserting Google Docs are *rejected* (the old behavior) were **intentionally rewritten** to the new convert behavior (AC-1) and to a non-convertible Form (AC-3) — this is the planned behavior change, not a deviation.
