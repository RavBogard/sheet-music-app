<objective>
## Goal
Org-scope the remaining AUTHED setlist read paths so a signed-in Brothers
Lazaroff user's dashboard shows ONLY BL setlists (currently it shows CRC's),
while CRC's authed dashboard stays byte-for-byte unchanged. This closes the
last known cross-tenant READ surface and completes the v11-04 phase.

## Purpose
v11-04-01 scoped the PUBLIC /perform read; v11-04-02 scoped consumer branding.
The authed `/setlists` dashboard still reads the `setlists` collection
cross-tenant (`getSetlistsPage` opt-in `org` is never passed; the 4 non-/perform
`subscribeToAllSetlists` callers pass no org). So David, signed in on
brotherslazaroff.live, would see CRC's services in his dashboard — the same leak
class the screenshot caught on /perform. The seams already exist: `getAllSetlists`
established the opt-in `.where('orgId','==',org)` pattern + the deployed
`(orgId,date)` composite index, and `subscribeToAllSetlists` already accepts an
`org?` arg (v11-04-01). This plan wires the authed callers to pass org.

## Output
`getSetlistsPage` (+ `getUpcomingSetlists`/`getRecentSetlists` for parity) gain an
opt-in `org` filter; the 2 server callers resolve org from `x-org-id`; the 4
client subscription callers pass `useOrg()`; regression tests; a deployed-surface
probe; David's authed-onboarding UAT appended to UAT-PENDING.md.
</objective>
