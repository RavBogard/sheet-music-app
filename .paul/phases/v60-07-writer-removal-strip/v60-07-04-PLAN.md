## Library reference
- Firebase Admin SDK: `db.batch()` returns a `WriteBatch`. `batch.set(docRef, data)` queues; `await batch.commit()` flushes atomically. Max 500 operations per batch — the importer enforces some upper bound on `items.length` via the rate limiter + practical UI flow; for safety, the plan asserts batch size ≤ 500 (or splits into multiple batches if larger).
- `FieldValue.serverTimestamp()` returns a sentinel that becomes a Firestore Timestamp on commit. Round-trips cleanly through `Timestamp.toMillis()` reads — fixes the audit-noted gap where ISO string `nowStr` doesn't.
