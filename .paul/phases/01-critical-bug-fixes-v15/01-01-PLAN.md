<acceptance_criteria>

## AC-1: AI Slot Lifecycle Safety
```gherkin
Given the AI chord scanner acquires an AI slot
When any code path exits (early return, error, success)
Then releaseAiSlot() is always called exactly once per acquisition
```

## AC-2: Annotation Save Timer Cleanup
```gherkin
Given a musician is in performance mode with unsaved annotations (within 800ms debounce)
When they navigate away from the perform page
Then clearSaveTimer() is called and a final save() is triggered before unmount
```

## AC-3: Musician Transposition Race Safety
```gherkin
Given a musician switches songs rapidly (file changes before async loadPref completes)
When the previous loadPref resolves after the new file is active
Then no stale setState calls execute (cancelled flag checked before every state update)
```

## AC-4: initAdmin Failure Handling
```gherkin
Given Firebase Admin credentials are missing or invalid
When any API route calls initAdmin()
Then a 500 error is returned to the client instead of proceeding with undefined Firestore
```

## AC-5: Firestore Data Sanitization Without JSON Roundtrip
```gherkin
Given a setlist with tracks containing undefined values
When createSetlist or updateSetlist is called
Then undefined values are stripped using explicit filtering (not JSON.parse/stringify)
And the data written to Firestore is identical to the JSON roundtrip result
```

  <name>Task 3: Replace JSON.parse/stringify with explicit sanitization</name>

  <action>
    **Replace JSON roundtrip sanitization:**
    - Create a local helper function `stripUndefined` at the top of setlist-firebase.ts:
      ```typescript
      function stripUndefined<T extends Record<string, unknown>>(obj: T): T {
        return Object.fromEntries(
          Object.entries(obj).filter(([, v]) => v !== undefined)
        ) as T
      }
      ```
    - For arrays of objects (tracks), create `stripUndefinedDeep`:
      ```typescript
      function stripUndefinedDeep(value: unknown): unknown {
        if (Array.isArray(value)) return value.map(stripUndefinedDeep)
        if (value && typeof value === 'object' && !(value instanceof Timestamp))
          return stripUndefined(value as Record<string, unknown>)
        return value
      }
      ```
    - Replace line 43: `JSON.parse(JSON.stringify(tracks))` → `stripUndefinedDeep(tracks) as SetlistTrack[]`
    - Replace line 52: `JSON.parse(JSON.stringify(additionalData))` → `stripUndefined(additionalData as Record<string, unknown>)`
    - Replace line 100: `JSON.parse(JSON.stringify(data))` → `stripUndefined(data as Record<string, unknown>)`
    - Important: The Timestamp import is already present (line 13). The stripUndefinedDeep helper must NOT strip Timestamp instances (they are valid Firestore values).
