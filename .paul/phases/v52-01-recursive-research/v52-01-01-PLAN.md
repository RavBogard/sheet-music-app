<objective>
## Goal

Run 4 parallel research tracks against the v5.2 issue list, capture real-iPad reproduction artifacts, and synthesize into a RESEARCH-SYNTHESIS.md that gives phases v52-02..05 a confirmed root-cause foundation — so execution phases fix the *systemic* cause, not surface symptoms.

## Purpose

Daniel's explicit ask for v5.2: **"systemic fixes, not bandaids."** Five user-visible bugs cluster suspiciously around iPad post-v51-01, which is a strong signal of shared-substrate causes (focus rule leakage, sync state visualization, touch-vs-hover affordance). Without research, phase 2–5 planning would have to guess at root causes and risks repeating the v5h-01 "3 wrong handoff hypotheses" pattern (postmortem §2). Front-loading research is the v5h-01 "2-3-strikes architectural-rethink rule" applied prophylactically.

## Output

- 4 track research reports in `.paul/phases/v52-01-recursive-research/track-{a,b,c,d}-*.md`
- 1 iPad UAT capture file documenting real-device repro data
- 1 `RESEARCH-SYNTHESIS.md` consolidating findings + phase-2..5 scope recommendations + open questions
- No source code modified
</objective>
