<objective>
## Goal
Two data-flow improvements: (a) exclude chartless items from print cover page, (b) persist last-used key per song so it "sticks" when re-added to future setlists.

## Purpose
(a) Printed gig packets should only show items musicians need charts for — service flow items like "Pre Service" or "V'ahavta" without PDFs clutter the cover page. (b) When Rabbi Daniel changes a song's key (e.g., transposes "Mi Chamocha" to D), that choice should carry forward to the next setlist without manual re-entry.

## Output
- Print cover page: only lists tracks that have a `fileId` (plus section headers for structure)
- PrintStats: count only chart-bearing tracks
- Sticky keys: when a track's key is changed, save `lastUsedKey`/`lastUsedTransposition` to `library_index`; when adding from library, prefer `lastUsedKey` over `nativeKey`
</objective>
