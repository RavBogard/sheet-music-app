<objective>
## Goal
Add admin UI for managing song groups and toggling the canLiveSwap permission on users. After this plan, admins can assign live-swap permissions and curate which songs are interchangeable for each liturgical slot.

## Purpose
The data layer from Plan 01 is complete but has no UI to manage it. Admins need to:
1. Toggle canLiveSwap on specific musicians (like the sound engineer toggle)
2. View, create, and edit song groups (which songs are alternatives for each liturgical slot)
3. Seed initial groups from liturgical templates

## Output
- canLiveSwap toggle button added to UserRow (mirrors sound engineer toggle)
- SongGroupSection component added to Manage page
- Seed button to auto-populate groups from templates
</objective>
