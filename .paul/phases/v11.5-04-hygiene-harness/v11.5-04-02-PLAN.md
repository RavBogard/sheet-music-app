<objective>
## Goal
Stop test/junk rows (`.DS_Store`, `[role-*] tiny` test-uid rows, orphaned/duplicate
catalog cruft) from appearing on the two BROWSER surfaces that lack a filter today —
the consumer library browse and the chart-bind picker — and guard the Drive-sync
ingestion path so new non-chart artifacts never land in `library_index`.

## Purpose
Daniel's directive: the band/consumer web surface must be bulletproof. Run-3 stress
confirmed junk showing on consumer library browse AND the bind picker. The MCP/agent
surface already hides junk (`list_library`/`search_library` use `isNonChartArtifactShape`);
the browser surfaces bypass it. This closes that gap with ONE shared, browser-safe
predicate so consumers and agents agree on what "junk" is.

## Output
- A pure (firebase-admin-free) `isJunkLibraryRow` predicate, single source of truth.
- Consumer browse + bind-picker filter junk via it.
- Drive sync skips non-chart artifacts at ingestion.
- Unit tests.
</objective>
