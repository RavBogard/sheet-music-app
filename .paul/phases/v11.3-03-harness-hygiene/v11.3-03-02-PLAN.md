<objective>
## Goal
Close BUG-1: orphaned `[role-*]` rows in CRC `library_index`. Two parts:
1. **Coverage gap (durable fix):** `sweep_orphan_test_data` currently sweeps orphan
   `setlists` + `setlistTemplates` only. Extend `sweepOrphanTestDataCore` to ALSO sweep
   orphan `library_index` rows — those whose `uploadedBy` is a test-shape uid AND whose
   owner user-record is absent (the exact shape that survives `cleanup_all_test_data`,
   because the cascade keys off live test accounts and these owners are gone).
2. **Prod cleanup (one-time, verify-first):** delete the two existing `[role-*]` orphan
   rows from CRC `library_index` after a dry-run probe confirms exactly those rows.

## Purpose
Hygiene: orphan `[role-*]` rows clutter the CRC library and are leftover stress-test
debris. The `library_index` cascade already exists on the *revoke* path (`CASCADE_FIELDS`
has `{collection:"library_index", field:"uploadedBy", storage:true}`); the gap is only in
the *owner-absent orphan* sweep. err-public is not in play (these are non-content junk rows
owned by deleted test accounts; no real musician data touched).

## Output
- `sweepOrphanTestDataCore` + its arg/result types + the tool description extended for `library_index`.
- Emulator regression cases citing run-1 §BUG-1.
- A prod sweep/probe script; the two CRC orphans deleted; re-probe shows zero.
</objective>
