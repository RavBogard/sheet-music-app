```gherkin
Given a LibraryFileRow in select mode
When the user clicks the row
Then the selection toggles via onToggleSelect callback
```

```gherkin
Given an UploadDialog
When the user selects an invalid file (wrong type or >25MB)

```

## AC-4: ScheduleCard displays status and handles accept/decline
```gherkin
Given a ScheduleCard with a pending assignment
When the user clicks Accept or Decline

```

```gherkin
Given a RabbiBanner with a rabbiName

Then the banner renders with correct role icon, colors, and guidance text
And when no match exists, the banner returns null
```

```gherkin
Given PrepRecommendations with items at various daysUntil values
```

## AC-7: NextServiceCard expanded coverage
