<objective>
## Goal
Add desktop/keyboard-friendly Move-Up + Move-Down buttons inside the expanded inline-edit panel for both song and flow rows (alongside the existing Delete). Bump SwapPicker max-height on tablet+ so musicians see more results without scrolling.

## Purpose
- Drag-handle reorder works on touch but is awkward on desktop (small grip, requires precise click-and-drag). Adding visible Move-Up / Move-Down buttons inside the existing expanded panel gives keyboard + mouse users the same affordance without crowding the collapsed row.
- SwapPicker `max-h-[70vh]` is fine on phones but wastes screen real estate on tablet portrait. Bumping to 85vh on `md:` and up shows ~5 extra results per scroll.

## Output
- New `onMoveUp` / `onMoveDown` props on `SongInlineFields` and `FlowInlineFields`; rendered as icon buttons next to Delete; disabled at first/last position.
- `SetlistEditorV2` wires the callbacks by computing the prev/next neighbour ids from the full `tracks` array at render time and currying them per row.
- `SwapPicker` outer panel: `max-h-[70vh] md:max-h-[85vh]`.
</objective>
