    New signature: async — reads Dexie + applies canonical resolver. Preserve the entire QueueItem mapping verbatim:

    ```ts
    const handleSelectSetlist = async (setlist: Setlist) => {
        // v60-06-05: read tracks from Dexie (canonical) with embedded-array
        // fallback via getTracksForSetlistClient — same 3-branch logic the
        // perf-view destination uses via useSetlistPerformance.
        let resolvedTracks
        try {
            const dexieTracks = await getDb()
                .tracks.where("setlistId")
                .equals(setlist.id)
                .sortBy("order")
            resolvedTracks = getTracksForSetlistClient(dexieTracks, setlist)
        } catch (err) {
            logger.error("[SetlistDrawer] failed to read tracks for setlist", err)
            return
        }

        if (resolvedTracks.length === 0) return

        const queue = resolvedTracks
            .filter(t => t.fileId)
            .map(t => ({
                name: t.title,
                fileId: t.fileId!,
                type: (t.fileId?.startsWith('db-') || t.fileId?.endsWith('.musicxml') || t.fileId?.endsWith('.xml') || t.fileId?.endsWith('.mxl'))
                    ? 'musicxml'
                    : t.fileId?.endsWith('.chordpro') ? 'chordpro' : 'pdf',
                audioFileId: t.audioFileId,
                bpm: t.bpm,
                transposition: t.transposition,
                key: t.key
            } as QueueItem))

        if (queue.length > 0) {
            setQueue(queue, 0, `/perform/setlist/${setlist.id}`, setlist.id)
            router.push(`/perform/${queue[0].fileId}`)
            setOpen(false)
        }
    }
    ```

    Critical:
    - Do NOT change the QueueItem .filter().map() shape — that's the queue contract consumed by the music store.
    - Do NOT remove the `if (queue.length > 0)` gate — preserves the no-op behavior when no playable tracks.
    - The original `if (!setlist.tracks || setlist.tracks.length === 0) return` early-out is REPLACED by the `if (resolvedTracks.length === 0) return` check after canonical resolution — semantically equivalent for the embedded-only legacy case, and stricter for the post-v60-07 case where embedded would be empty but Dexie has rows.
    - Async event handlers are fine in React (no .catch needed at the call site).
    - If `logger` isn't already imported, confirm via grep — it IS (line 14 in current file: `import { logger } from "@/lib/logger"`).
    - getDb() returns the Dexie instance synchronously; the .where().equals().sortBy() chain returns a Promise<LocalTrack[]>.

    Avoid:
    - Introducing useEffect / useState for pre-loading Dexie data when drawer opens (premature optimization; click-time fetch is fast and only fires on actual select).
    - Wrapping the function in useCallback (existing handler isn't useCallback'd — no need to introduce here).
    - Adding a loading spinner (Dexie read is sub-millisecond for the row count involved; UX flicker not warranted).
    - Removing the early-return for empty resolvedTracks (would break the no-op contract for unselectable setlists).
  </action>
