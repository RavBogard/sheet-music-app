<objective>
## Goal
Migrate the two dashboard surfaces that show **total** track counts to read from the parent doc's `setlist.trackCount` (already maintained by the v54-01-03 reconciler) with a fallback to the embedded array length. Smallest-fix entry point into v60-06 dashboard reader migration. Two single-expression swaps.

## Purpose
Dashboard cards render across many setlists; loading each into Dexie via `useLiveQuery` would trigger the lazy-hydration cascade for every visible setlist (opposite of what v50-07-03 intends). Instead, dashboards read denormalized fields on the parent doc. For total counts, `setlist.trackCount` is already maintained: the v54-01-03 reconciler in `SetlistGridHydrator` writes it on every track-count change. Migrating dashboard counts to read `setlist.trackCount` (with `setlist.tracks?.length` fallback for legacy setlists pre-v54-01-03 or never edit-opened) lets us drop the embedded-array dependency from these surfaces without introducing a Dexie read path for list contexts.
