<objective>
## Goal
Fix PDF health scanner false positives — currently reports every PDF as problematic.

## Purpose
The scanner is supposed to identify genuinely corrupt or inaccessible PDFs so they can be archived. Instead, it flags everything, making it useless.

## Output
- Scanner correctly validates PDFs using workerless pdfjs mode
- Strict mimeType filtering prevents non-PDFs from being scanned
- Valid PDFs report as "healthy"
</objective>

<task type="auto">
  <name>Task 1: Fix false positives with workerless pdfjs and strict filtering</name>
  <files>src/lib/pdf-health-scanner.ts</files>
  <action>
    Two changes to pdf-health-scanner.ts:

    1. **Workerless pdfjs**: Replace the worker URL setup (lines 86-88) with:
       `pdfjs.GlobalWorkerOptions.workerSrc = ""`
       This disables the web worker and runs pdfjs in the main thread, avoiding worker URL 404 issues. The scanner only needs to validate PDFs (check page count), not render them, so performance is fine. This matches the pattern used in pdf-chord-extractor.ts.

    2. **Strict mimeType filter**: Change the filter (lines 27-29) from:
       `f.mimeType?.includes('pdf')` (too loose — could match anything containing "pdf")
       To: `f.mimeType === 'application/pdf'` (exact match)
       Keep the `.pdf` extension fallback.
  </action>
  <verify>
    - npx tsc --noEmit passes
    - Worker is disabled (workerSrc = "") not set to versioned URL
    - mimeType filter uses exact match
  </verify>
  <done>AC-1 and AC-2 satisfied: Scanner uses workerless mode and strict filtering</done>
</task>
