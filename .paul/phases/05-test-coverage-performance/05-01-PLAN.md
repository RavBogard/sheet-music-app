## Goal
Lazy-load PrintModal with next/dynamic and wrap ChatPanel in a dedicated error boundary. These are the performance optimizations from the v3.1 bugsweep.

## Purpose
PrintModal bundles jsPDF/jszip which are heavy. Lazy-loading prevents them from increasing initial page load. ChatPanel (AI features) should not crash the entire setlist view if it errors.

## Output
