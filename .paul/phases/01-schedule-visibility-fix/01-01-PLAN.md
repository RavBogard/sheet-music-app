<objective>
## Goal
Fix the schedule page so that all setlists with upcoming event dates appear, even when no musicians have been assigned yet.

## Purpose
Currently, the schedule page only shows services that have musician assignments (from `scheduling_assignments` collection). A setlist with an `eventDate` set but no musicians assigned is invisible on the schedule — making it appear "broken" to the band leader. This is the root cause of the March 14 service not appearing.

## Output
- Modified schedule page that shows all upcoming setlists with event dates
- Services without assignments shown with a clear "No musicians assigned" state
- Services with assignments continue to work exactly as before
</objective>
