<objective>
## Goal
Close the two remaining v11.7-06 upload/cache tenancy gaps:
1. `finalize_chart_upload` (signed-URL path) does not org-stamp the new chart →
   add an optional `org` to `finalizeChartUpload` and stamp the NEW chart from
   the handler's `orgFrom(extra)`, **skipping heal mode** (existing chart).
2. Anon chord-cache writes (`POST` chordData + `PATCH` native-key/last-used) on
   `/api/library/chord-cache` write by `fileId` with NO tenancy check → guard both
   against the host org so a broslaz-anon write can't cross to a CRC chart's row.

## Purpose
Both are deferred cross-tenant write gaps on the hard wall. The chunked-commit
path already stamps org (library-upload-session.ts:1049); the signed-URL finalize
shares finalize's missing-stamp gap → its uploads land default-org. The chord-cache
route is `requireAuth:false` (benign derived data) but has zero tenancy check, so a
cross-tenant `fileId` write is currently possible. err-public holds WITHIN a tenant;
this enforces the wall ACROSS tenants for both writers.

## Output
- `finalizeChartUpload(uid, args, org?)` stamps NEW charts (not heal) when org given.
- `finalize_chart_upload` handler passes `orgFrom(extra)`.
- chord-cache POST + PATCH reject a definite cross-tenant `fileId` write (403);
  same-tenant and row-absent writes proceed unchanged.
- Emulator + route tests; tsc 0; `next build --webpack` 0.
</objective>
