- **Fix:** Use `"brotherslazaroff"` (the real OrgId) in the BL test case.
- **Files:** `src/app/api/recordings/upload/__tests__/route.test.ts`
- **Verification:** 3/3 route tests pass.

**Secondary note (test infra):** Building a real multipart request via `new NextRequest(url, {headers, body: formData})` suppresses undici's auto multipart Content-Type when an explicit Headers object is passed → `formData()` threw. Resolved by stubbing `req.formData()` directly (test targets org-stamping, not multipart parsing).
