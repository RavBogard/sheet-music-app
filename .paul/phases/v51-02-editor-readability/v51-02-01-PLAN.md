<objective>
## Goal
Tighten setlist editor density and lift visual hierarchy across desktop + tablet so the eye instantly finds title > key > lead/type > notes, and section-header rows (type='header') visually frame the rows below them. Mobile parallel render path (MobileCardList) is NOT touched.

## Purpose
Daniel reports the editor reads "too spaced out and too uniform" — rows blend together, hierarchy doesn't help him scan a setlist. This plan is the band-onboarding gate's content-readability pass: before he hands the band tablets, the editor must look intentional, dense without being cramped, and section-aware. Aesthetics here directly determine whether Daniel feels comfortable inviting the band to the app.

## Output
- New `.paul/phases/v51-02-editor-readability/v51-02-01-DESIGN-CONTRACT.md` capturing the locked density/hierarchy/section-treatment numbers (ground truth that Tasks 3-4 implement against)
- Tightened SetlistGrid + cell components rendering at the locked density on desktop + tablet, with type/title/key/lead/notes typographically + chromatically ranked, and `type='header'` rows visually framed
- jest-axe coverage in `SetlistGrid.a11y.test.tsx` proving WCAG AA holds at the new density
- Production-deployed editor that Daniel approves on desktop + iPad before phase-close
</objective>


```gherkin

```

## AC-3: Visual hierarchy ranks fields
```gherkin
Given a content row with title + key + leadMusician + type + notes populated
When the row renders

  And key is secondary-prominent (key-left layout from v1.6 P3 preserved; same weight tier)
  And leadMusician + type are tertiary (muted color OR smaller weight)
  And notes is quaternary (smallest weight OR most muted color)
  And the locked typographic + color scale is documented in DESIGN-CONTRACT.md and matches the rendered output
```

```gherkin
  And the eye can scan from one section header to the next without reading row-by-row
  And header rows still expose the same edit affordances (title editable, type-cell switchable) — no behavior regression
```
