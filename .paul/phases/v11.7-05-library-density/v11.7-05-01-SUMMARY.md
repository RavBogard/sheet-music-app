### Auto-fixed Issues
**1. [CSS] `xs:` breakpoint would have hidden the composer everywhere**
- **Found during:** Task 2 (composer sub-label).
- **Issue:** First draft used `hidden xs:inline`; `xs` is not a configured Tailwind breakpoint here, so the composer would be permanently hidden (AC-3 fail).
- **Fix:** Made the composer always-visible with `truncate shrink min-w-0` (text-only, never overflows).
- **Verification:** LibraryFileRow.test asserts the composer text node renders.

### Plan-spec note (not a deviation)
- The plan suggested adding a composer assertion to `song-charts-library.test.tsx`, but that file **mocks** `LibraryFileRow` (so it can't assert row internals). Added a dedicated `LibraryFileRow.test.tsx` instead — same coverage intent, correct layer.
