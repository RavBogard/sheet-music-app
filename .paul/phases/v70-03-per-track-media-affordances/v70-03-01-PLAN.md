<objective>
## Goal
Give a bound chart a click-through affordance in the setlist row card: activating
the chart indicator on a track that has a chart bound opens that chart file in a
new browser tab. Unbound rows keep today's behavior (a non-interactive indicator
icon; binding stays on the context menu / edit-pane "Bind Chart" button).

## Purpose
v7.0 is "feed a doc, get a setlist" — but once charts are bound, the band still
needs to *see* them. Today the chart indicator in the row card is a plain
non-interactive `<span>`; there is no way to view the chart a row points at from
the setlist. This closes that gap with the smallest possible surface change,
reusing the existing `/api/drive/file/[fileId]` (and `/api/library/file/[id]`)
Storage-backed serving routes.

## Output
- `MobileRowCard`'s chart indicator becomes a click-through link when the track
  has a chart bound — an `<a target="_blank">` pointing at the chart serving URL.
- Unbound rows: the chart indicator stays exactly as today (non-interactive icon).
- The link does not interfere with the card's tap-to-edit or long-press
  context-menu gestures.
- Tests covering bound-renders-link, unbound-renders-plain-icon, and
  link-click-does-not-toggle-edit.
</objective>

    Change:
      - BOUND (`track.songId` is set): render an `<a>` instead of the plain span:
        - `href` = the chart serving URL. Build it with `parseFileId(contentId).apiUrl`

          `/api/drive/file/{id}` otherwise). `contentId` = `track.fileId` if it is a

          guard with `typeof track.fileId === 'string' && track.fileId`).
        - `target="_blank"`, `rel="noopener noreferrer"`.
        - `aria-label="Open chart in new tab"`.
        - `onClick`: call `e.stopPropagation()` so the click does NOT bubble to the
          card's `handleCardClick` (which toggles the edit pane). This is the key
          interaction guard — without it, opening the chart also toggles editing.
          Do NOT preventDefault — the anchor must still navigate.
        - Styling: keep the existing `Music` icon + the bound look
          (`text-brand opacity-80`), add `cursor-pointer` and a hover affordance
          (e.g. `hover:opacity-100 transition-opacity` or a brand color shift —
          pick per /ui-ux-pro-max). Ensure a ≥44px touch target on coarse pointers:
          add padding (e.g. `p-2 -m-2` to grow the hit area without shifting
          layout) and `[@media(pointer:coarse)]` sizing similar to how other touch
          targets in this file are handled. Keep `flex-none ml-2`.
      - UNBOUND (`track.songId` falsy): leave the EXACT existing markup — the
        non-interactive `<span>` with the `<FileText>` icon and
        `aria-label="No chart bound"`. Do not make it interactive.

    Implementation shape: a small conditional inside the JSX where the `<span>` is
    today — `track.songId ? <a .../> : <span .../>`. Keep it minimal; do not
    extract a new component (the dead-path `ChartCell` is not reused — see the
    RENDER-PATH NOTE).

    Avoid: touching `SetlistGrid.tsx`, `ChartCell.tsx`, or `ChartBindPopover`
    (dead path); introducing a new serving route; changing storage.rules;
    changing the context-menu / edit-pane binding affordances; changing the
    long-press or drag-handle pointer logic.
