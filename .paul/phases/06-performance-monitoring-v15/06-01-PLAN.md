       - Add `browserTracingIntegration()` to integrations
       - This automatically captures LCP, FID, CLS, TTFB

    3. Update CSP in next.config.ts headers to allow Sentry connections:
       - Add `https://*.ingest.sentry.io` to connect-src
       - Add `https://*.sentry.io` to connect-src
    4. Conditionally apply withSentryConfig: only wrap if DSN is set, to avoid build overhead when Sentry is disabled.
  </action>
  <verify>`npx tsc --noEmit` passes. Build succeeds. Sentry DSN environment variable controls activation.</verify>
  <done>AC-2 satisfied: Sentry source maps + Web Vitals configured</done>
