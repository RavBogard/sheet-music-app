<objective>
## Goal
Fix the broken print pipeline (500 error) and simplify the PrintModal UI. Replace the Inngest background job architecture with direct synchronous PDF generation (matching the working personal/public routes). Redesign the modal for clarity and reliability.

## Purpose
Gig packet generation is an essential feature for the worship band. The current implementation fails with a 500 because Inngest isn't configured on Vercel. The UI also has issues: black background fills the screen before the print menu is visible. This must be bulletproof and simple.

## Output
- API route generates PDFs synchronously (no Inngest dependency)
- PrintModal fetches PDF directly as blob (no Firestore polling)
- Simplified, clean modal UI
</objective>

  <name>Task 1: Convert API route from Inngest async to direct synchronous generation</name>
  <files>src/app/api/setlist/print/route.ts</files>
  <action>
    Rewrite the POST handler to generate the PDF synchronously and return it as a blob response, matching the personal/public route pattern.

    Current flow (broken):
    1. POST → inngest.send("pdf/generate") → return { jobId }
    2. Client polls Firestore for job completion
    3. Client fetches signed URL

    New flow (simple):
    1. POST → generatePrintPdf(body) → return PDF blob

    Implementation:
    1. Remove inngest import and randomUUID import
    2. Keep createApiHandler, checkRateLimit, schema validation
    3. Call `generatePrintPdf(body)` directly (import from print-pipeline)
    4. Return the PDF as a NextResponse with:
       - Content-Type: application/pdf
       - Content-Disposition: attachment; filename="gig_packet.pdf"
    5. Use Buffer.from(result.pdf) for the response body
    6. Build filename from body.title (sanitized) if available

    Keep maxDuration = 120 (generous for large setlists).
    DO NOT modify the schema validation.
    DO NOT modify print-pipeline.ts.
    DO NOT delete the Inngest files (they're unused now but harmless).
  </action>
  <verify>
    - `npx tsc --noEmit` passes
    - Route no longer imports from inngest
    - Route returns PDF blob directly
