<objective>
## Goal
Build inline song swap for leaders in the performance view: tap a song → fuzzy search picker with name matches from library → pick replacement → Firestore updates → everyone sees the change. Plus toast notifications when tracks change.

## Purpose
Leaders need to quickly sub songs during live services. Most swaps are between similarly-named songs (e.g., Barechu variants). The existing Firestore real-time sync means everyone's view updates automatically — we just need the edit UI.

## Output
- SwapPicker component (bottom sheet with fuzzy search)
- SwapChangeToast component (detects track changes, shows toast)
- Performance page wired up with swap flow for leaders
- Swap updates Firestore tracks array directly
</objective>

    **Logic:**
    - Use a ref to store the previous tracks array
    - On tracks change: compare old vs new by index
    - For each changed track (where title differs): show toast "{old title} → {new title}"

    - Dedup: don't re-toast the same change (track by a swap counter or timestamp)

    - This component renders nothing visible — it's a side-effect component
    - Only fires toasts for changes made by OTHER users (not the leader who did the swap)
