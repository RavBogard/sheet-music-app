<objective>
## Goal
Add error handling to swapLiveTrack and add onSnapshot error callbacks to all Firestore listeners missing them (~12 instances across 11 files).

## Purpose
Silent Firestore listener failures are invisible — they just stop updating. Musicians during a live service would see stale data with no indication of a problem. Adding error callbacks ensures failures are logged and observable.

## Output
11 files hardened with proper error callbacks on all onSnapshot listeners + swap error handling.
</objective>
