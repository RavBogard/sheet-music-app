<objective>
**Goal:** Fully eliminate the private/public setlist distinction. Remove `isPublic` from the code (type, schema, service signature, every caller) and from existing Firestore data, so that any user can see any setlist.

**Purpose:** v4.0 Phase 2 only removed the list-view filter but left `isPublic` threaded through the codebase. Multiple API routes still hardcode `isPublic: false`, which creates invisible setlists and blocks Rabbi Daniel from onboarding the band.

**Output:** `isPublic` does not exist in the codebase; existing Firestore docs no longer carry `isPublic: false`; a regression-guard test ensures the field cannot be silently reintroduced.
</objective>
