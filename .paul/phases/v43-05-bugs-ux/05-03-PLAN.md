<objective>
## Goal
Close audit finding **U01** — guarantee every interactive element on primary musician-facing routes (`/perform/**`, `/setlists`, mobile tab bar) has a hit box ≥ 44×44 CSS pixels (WCAG 2.5.5 AAA / iOS HIG).

## Purpose
Musicians operate the app live — on stage, holding an instrument, in low light. Sub-44px targets produce mis-taps during performance, which is the single highest-stakes failure mode of the app. This is a band-onboarding gate (per PROJECT.md "bulletproof and easy and intuitive").

## Output
- All interactive elements on listed routes meet the 44px floor
- Regression test asserting sizing of the known-offender surfaces
- `05-03-SUMMARY.md` documenting what was fixed and what was already compliant
</objective>
