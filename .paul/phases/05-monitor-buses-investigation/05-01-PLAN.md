<objective>
## Goal
Investigate and fix the missing 5th monitor bus. Add a visual indicator in the admin Sound System section showing the current bus count so admins can easily spot and correct misconfiguration.

## Purpose
User expected 5 monitor buses but only 4 are visible. Investigation shows the web app defaults to `[1,2,3,4,5]` but Firestore `config/monitor` document may have `monitorBuses` saved as `[1,2,3,4]`, overriding the default via spread merge. The code has no bugs — this is a data issue. We need to verify the Firestore data and add a clear bus count display in admin so this is easy to diagnose in future.

## Output
- Verified Firestore config/monitor document has correct monitorBuses array
- Admin Sound System section shows bus count badge next to the bus input field
</objective>
