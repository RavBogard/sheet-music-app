<objective>
## Goal
Completely remove the PDF annotation/drawing feature — delete all annotation-only files and strip annotation references from mixed files.

## Purpose
The annotation feature (freehand drawing, text, highlight on PDF charts) won't be meaningfully used by the worship band. Removing it simplifies the codebase, reduces the PerformanceToolbar surface area, and eliminates dead code before Phase 8 (Performance UX Fixes) modifies the same toolbar.

## Output
- 5 files deleted (annotation store, types, test, toolbar, layer)
- 6 files edited to remove annotation imports/usage
- ~100 lines of annotation code removed
- All remaining features intact
</objective>
