<objective>
## Goal
Eliminate the private/public setlist distinction. All setlists become public. Remove personal tab, isPublic toggles, copyToPersonal, subscribeToPersonalSetlists. Simplify Firestore rules and access checks. Keep ownerId for "created by" display.

## Purpose
Private setlists serve no purpose for CRC — all setlists should be visible to everyone. This simplifies the codebase and removes user confusion about personal vs public.

## Output
- All setlists treated as public
- Single setlist subscription (no personal/public split)
- No personal tab in dashboard
- No public/private toggle in create dialog
- Simplified Firestore rules
</objective>
