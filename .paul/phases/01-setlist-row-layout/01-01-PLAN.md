<objective>
## Goal
Fix setlist perform view layout: key badge directly next to song title, notes inline next to key in a distinct color, and alternating row backgrounds for readability.

## Purpose
Musicians reading setlists during live performance need to quickly scan song name → key → notes in a natural left-to-right flow. Currently the key is pushed to the far right by flex-1, making it hard to associate with the song name. Alternating rows help track across long setlists on tablets.

## Output
Modified SetlistRow.tsx, SetlistView.tsx, and SetlistDrawer.tsx with improved layout.
</objective>

## AC-1: Key badge positioned directly after song title
```gherkin
Given a setlist in perform view with songs that have key assignments
When the setlist renders on any screen width
```

## AC-2: Notes displayed inline next to key in distinct color
```gherkin
Given a setlist track has notes
When the setlist row renders
Then the notes text appears inline on the same line as the title and key (after the key badge)
And the notes text uses a warm/amber color (text-amber-400/70 or similar) distinct from the brand-indigo key badge
And the notes text truncates with ellipsis if too long
```

## AC-3: Alternating row backgrounds for readability
```gherkin
Given a setlist with multiple tracks in perform view
When the setlist renders

And odd-indexed rows have no additional background
And the current-position highlight (bg-brand/20) takes precedence over alternating color
And header/divider rows are not affected by alternating
```
