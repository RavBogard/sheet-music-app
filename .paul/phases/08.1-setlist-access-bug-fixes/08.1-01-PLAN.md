<objective>
## Goal
Fix two production-breaking bugs preventing band members from accessing legacy setlists, backfill missing ownerId on all existing setlists, and improve error messaging for Firestore permission failures.

## Purpose
Band members currently get blank pages or redirects when viewing any setlist that predates the ownerId field. Admin can't save changes to these setlists either. This blocks all live usage of older setlists.

## Output
- Updated Firestore rules with admin fallback and band leader read access
- Fixed server-side ownership check for missing ownerId
- One-time migration script to backfill ownerId
- Improved auto-save error messages
</objective>
