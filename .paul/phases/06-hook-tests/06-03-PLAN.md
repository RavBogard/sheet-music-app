
```gherkin
Given the monitor connection hook
When multiple components mount/unmount
Then the singleton connection is established once, ref-counted, debounce-tears-down on last unmount, and reconnects on visibility change
```

```gherkin
Given a user creating a setlist via wizard
When they select a template, fill details, and submit
Then the hook navigates steps correctly, auto-fills from template, creates the setlist, assigns musicians, and navigates to the result
```

```gherkin
Given a logged-in user on the setlist dashboard

```
