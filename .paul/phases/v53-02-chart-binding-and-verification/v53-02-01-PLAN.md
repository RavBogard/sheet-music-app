<objective>
## Goal
Make chart binding work end-to-end on iPad: typing in the picker actually filters results (cmdk value-format fix); the picker proactively shows Daniel's most-recently-used charts at the top (Recent section); the library is hydrated from Firestore at setlist mount so the picker has data to filter against (priming); and the ChartCell column is discoverable on iPad without horizontal scrolling past Notes (affordance choice locked by /ui-ux-pro-max consultation in-context).

## Purpose
Chart binding is the substrate-level UX gap that v50-05's editor cutover left exposed: the picker filter has been broken since v50-05-01 (cmdk `${title} ${id}` value-format scoring bug), the songs library never auto-hydrates so first-session opens see an empty picker, there's no recency surface even though `SongRecentEntry.performedAt` (v50-04) already tracks last-use timestamps, and the Chart column lives off-screen on iPad. Daniel's stated workflow ("90% same week to week") makes recency a dominant signal — Recent above Library is the right hierarchy. This plan ships the systemic fix (NOT smallest-fix) per Daniel's discuss-phase decision so the same songs stay one tap away through weekly worship cycles.

## Output
- ChartBindPopover with restored typing-to-filter + new "Recent" section above "Library" (sorted by `songs.recent[0]?.performedAt` desc; cap 5; hidden when empty).
- AddRowPlaceholder with restored typing-to-filter (cmdk value-format fix only — Recent section deferred per scope).
- New `src/lib/songs/prime.ts` exporting `primeSongsLibrary({ db?, firestore?, limit? })` helper.
- SetlistGridHydrator gains fire-once-per-mount priming effect calling `primeSongsLibrary` after Dexie hydration.
- ChartCell column discoverable on iPad — choice between column-reorder / sticky-right / row-gutter affordance locked by /ui-ux-pro-max consultation at the in-plan decision checkpoint.
- iPad UAT verification by Daniel on real production after Vercel auto-deploy.
- SUMMARY at `.paul/phases/v53-02-chart-binding-and-verification/v53-02-01-SUMMARY.md`.
</objective>
