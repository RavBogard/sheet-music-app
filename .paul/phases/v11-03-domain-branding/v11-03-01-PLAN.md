<objective>
## Goal
Resolve the request host to a tenant org at the Edge and propagate that org through the whole browser render — server (RSC) and client — so v11-03-02 (branding) and v11-03-03 (vocab) have a single org source to theme/label against. **Zero visual or behavioral change** in this plan: `brotherslazaroff.live` still renders the current CRC look; it just now *knows* it is the `brotherslazaroff` org.

## Purpose
This is the v11-03 foundation. The MCP surface is already tenant-isolated (v11-02), but the **browser surface** has no org awareness on the client. brotherslazaroff.live must serve the shared deployment while resolving to the BL tenant for chrome + copy. Mirrors the existing `x-nonce` Edge→RSC header seam in `src/proxy.ts`.

## Output
- `src/proxy.ts` resolves `resolveOrgIdByDomain(host)` and forwards an `x-org-id` request header (alongside the existing `x-nonce`).
- `src/app/layout.tsx` reads `x-org-id`, stamps `<html data-org="…">`, and wraps the tree in `<OrgProvider>`.
- New `src/lib/org/org-context.tsx` — client context + `useOrg()` hook.
- Unit tests for the resolver host cases + the provider/hook.
</objective>

<task type="auto">
  <name>Task 1: Resolve org in the Edge proxy and forward x-org-id</name>
  <files>src/proxy.ts</files>
  <action>
    In `proxy()`, after the `requestHeaders` Headers object is built (it already
    sets `x-nonce`), resolve the org from the request host and forward it:
    - Import `resolveOrgIdByDomain` from `@/lib/org/registry` (pure, no Firestore
      → Edge-safe; do NOT import membership.ts which uses firebase-admin).
    - Resolve host via `request.headers.get('host')` (fallback
      `request.nextUrl.hostname`). Call `resolveOrgIdByDomain(host)`.
    - `requestHeaders.set('x-org-id', orgId)`.
    This must happen BEFORE the early `nextWithHeaders()`/`rewriteWithHeaders()`
    returns so every passthrough/rewrite (incl. API routes, social-crawler,
    vestigial 404, authed pages) carries the header. Place it right after the
    existing `requestHeaders.set('x-nonce', nonce)` line so all return paths
    inherit it.
    Avoid: changing any existing auth/redirect/CSP logic; do not strip an
    inbound client-supplied `x-org-id` separately — `new Headers(request.headers)`
    copies it but the unconditional `.set()` overwrites it, which is the desired
    trust boundary (Edge is authoritative). Do not read cookies/claims here — host
    is the only org source for the browser surface.
  </action>
  <verify>Grep shows `requestHeaders.set('x-org-id', …)` immediately after the `x-nonce` set; `npx tsc --noEmit` clean. Manual reasoning: every `return` in proxy() flows through nextWithHeaders/rewriteWithHeaders/withSecurityHeaders which all use `requestHeaders`.</verify>
  <done>AC-1 + AC-2 (Edge half): x-org-id is set on the forwarded request headers for every matched route, value from resolveOrgIdByDomain(host).</done>
</task>
