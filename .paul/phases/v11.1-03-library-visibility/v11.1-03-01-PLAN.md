<objective>
## Goal
Host-isolate the in-app chart library so each tenant's generic Library tab (and the chart-bind picker + header search that read the same pool) shows ONLY that host org's `library_index` charts — with an **admin-only "All sites" toggle** to reveal the full cross-tenant pool for authoring/binding. broslaz gets org-neutral tab labels. CRC is byte-identical. Display-only — direct chart links/access are NEVER gated (err-public).

## Purpose
The generic Library tab currently shows BOTH tenants' charts because the HTTP/SSR read paths were never org-scoped (only MCP was). On brotherslazaroff.live this clutters the band's library with CRC's entire catalog. This is the P1 consumer-surface de-clutter for v11.1.

## Output
- `getServerLibrary`/`getServerLibraryLean` accept an optional `orgId` → filter `library_index` rows by `rowOrg(orgId)`.
- `(main)/library/page.tsx` resolves the host org (`x-org-id`) and passes it to both `getServerLibrary` and `SongChartsLibrary`.
- `/api/library/list` filters to the host org by default; an `allSites=true` param is honored ONLY for admins (gated via `getServerUser().isAdmin`).
- `useLibrary`/`fetchLibrary` gains an `allSites` flag; the All-sites re-fetch re-hydrates the store → tab + bind-picker + header search all follow.
- `SongChartsLibrary` renders org-neutral tab labels for non-crc orgs (broslaz: "Charts / Uploads / Audio", no Shireinu) and an admin-only "All sites" toggle.
</objective>
