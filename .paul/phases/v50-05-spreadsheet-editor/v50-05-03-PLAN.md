## Goal
Add multi-select + bulk batch-edit toolbar (ARCHITECTURE.md §6.6) on top of the v50-05-02 SetlistGrid mount, and swap `window.confirm` for a shadcn `AlertDialog` via a React-context provider — landing the highest-leverage weekly-workflow polish (bulk Key / Lead / Type / Delete) and the safer destructive-action affordance, without disturbing v50-05-01/02 contracts.

## Purpose
v5.0's whole point is "bulletproof and easy and intuitive." The `tweak 2-3 songs` weekly clone-and-edit workflow currently requires N round-trips through individual cells when the user changes the lead musician or transposes for a service. Multi-select + bulk-edit collapses that into one action. AlertDialog replaces the abrupt browser-native `window.confirm` (already injection-pointed via `confirmDeleteWithTitle` per v50-05-01) with a themed, focus-trapped, animation-respectful destructive-action dialog. Both are user-visible polish that makes the cutover-quality editor feel finished. Defers the iPad / mobile / WCAG / Undo / ContextMenu work to v50-05-04 and v50-05-05 to stay inside plan-format.md's 2-3-tasks scope guidance.
