<objective>
## Goal
Land the second of three v50-05 polish plans: iPad / pointer-coarse touch variant (Radix Popover → Radix Sheet swap across 6 dropdown sites + 44px minimum touch targets + always-visible hover-replacements + long-press) and right-click ContextMenu (Edit / Bind chart / Duplicate / Delete) with selection-aware action targeting that routes Delete through the v50-05-03 DeleteConfirmProvider.

## Purpose
ARCHITECTURE.md §6.7 — the editor must work on iPad/touch as a first-class surface, not as a degraded desktop. Cell dropdowns rendered as floating Popovers are unreachable on iOS Safari (small target, off-screen positioning, no hover affordance reveal). Right-click + long-press ContextMenu is the missing power-user affordance for "edit / duplicate / bind / delete" without navigating to the toolbar. Ships the bulletproof-and-intuitive criterion for tablet musicians ahead of v50-05-05 (mobile + WCAG + Undo) and band onboarding.

## Output
- New `<TouchOrPopover>` wrapper component that picks Radix Popover or Radix Sheet based on `useMediaQuery('(pointer: coarse)')` — single integration point covering all 6 swap sites.
- DropdownCell (covers KeyCell + LeadCell + TypeCell), AddRowPlaceholder, ChartBindPopover, and BatchActionBar's inline BulkPopover all routed through TouchOrPopover.
- 44px touch-target padding bump on cells at `(pointer: coarse)` breakpoint; drag-handle column width 44px → 52px; hover-only affordances become always-visible on touch.
- ChartBindPopover refactored to controllable open state (lifted to `open` + `onOpenChange` props) so SetlistGrid can open it programmatically from ContextMenu "Bind chart".
- Radix ContextMenu mounted on rows + drag handle with 4 actions (Edit row / Bind chart / Duplicate row / Delete row) — selection-aware: actions target the multi-selection when right-clicked row is part of `selection.selectedIds` AND size ≥ 2; otherwise target just the right-clicked row.
- 500ms long-press on touch opens the ContextMenu programmatically (touch devices don't fire `contextmenu` reliably).
- `.paul/phases/v50-05-spreadsheet-editor/v50-05-04-SUMMARY.md` after UNIFY.
</objective>

## AC-5: ContextMenu actions are selection-aware
```gherkin
Given the user has multi-selected 3 rows via Cmd-click on drag handles (selection.selectedIds.size === 3)

And the AlertDialog renders with bulk copy: "Delete 3 rows?"
And confirming deletes all 3 rows + clears selection

Given the user has multi-selected 3 rows
When the user right-clicks a NON-selected row and picks "Delete row"
Then the action targets only the right-clicked row (the multi-selection is untouched)
And the AlertDialog renders with row copy: "Delete row?" with the right-clicked track's title quoted
```

## AC-6: ContextMenu Edit row + Bind chart + Duplicate row work
```gherkin
Given the user is on /setlists/[id] with at least one track

When the user right-clicks a row and picks "Duplicate row"
```
