<objective>
## Goal
Move the hamburger menu from the bottom-right tab bar to a new mobile header bar in the upper-left, following standard mobile navigation conventions.

## Purpose
The current bottom-tab hamburger placement breaks user expectations — mobile users expect the main menu toggle in the upper-left. The drawer already opens from the left, so the trigger should match. This improves usability for tablet and phone users during live services.

## Output
- New `MobileHeader.tsx` component with hamburger icon (upper-left) and app branding
- `MobileTabBar.tsx` cleaned up: Menu button removed, only navigation tabs remain
- Layout padding adjusted: mobile gets top padding for the new header
</objective>
