  <name>Task 1: Parallel codebase scan with subagents</name>
  <files>src/app/api/**, src/lib/**, src/hooks/**, src/components/**</files>
  <action>
    Launch 4 parallel Explore subagents to scan the codebase:

    **Agent 1 — API Routes & Auth:**
    - Scan all 55 API routes for: missing auth checks, inconsistent error handling, unvalidated inputs, hardcoded secrets, missing rate limiting
    - Audit withAuth vs createApiHandler usage (track the migration gap)
    - Check for proper HTTP method handling and response codes
    - Flag any routes missing proper error responses

    **Agent 2 — Data Layer & Firebase:**
    - Scan all Firestore operations for: missing error handling, unindexed queries, data consistency issues
    - Review Firebase Storage usage patterns
    - Check Google Drive integration for timeout/error handling
    - Audit security rules implications from code patterns
    - Review the bridge credentials situation (CRIT-003)

    **Agent 3 — Frontend Hooks & State:**
    - Scan all 18 hooks for: memory leaks (missing cleanup), stale closures, race conditions
    - Review Zustand stores for state management issues
    - Check for proper cleanup in useEffect hooks
    - Audit clearSaveTimer() wiring (deferred issue)
    - Look for unhandled promise rejections in async hooks

    **Agent 4 — Dependencies & Config:**
    - Review package.json for outdated/vulnerable dependencies
    - Check next.config.ts for suboptimal settings
    - Review build configuration and bundle size concerns
    - Assess PWA/service worker configuration
    - Check for deprecated API usage patterns
  </action>
