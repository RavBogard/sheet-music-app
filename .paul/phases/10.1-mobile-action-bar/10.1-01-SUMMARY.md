**Rewrote MobileTabBar from navigation links into a three-button action bar: Search (Fuse.js popover), Setlist (session-aware navigate to perform mode), Monitor (QuickMonitorPanel popover).**

## Accomplishments

- Transformed MobileTabBar from redundant page navigation into a live-resources action bar for mid-service use
- Search uses Fuse.js over the already-hydrated library store — zero additional network requests
- Setlist button smart-navigates: session-opened setlist → nearest upcoming eventDate → /setlists fallback
- PDF view detection hides bar when PerformanceToolbar takes over

## Decisions Made

| Decision | Rationale | Impact |
|----------|-----------|--------|
| Fuse.js over useContentSearch API | Library store already hydrated in memory; avoids network latency for search | Instant search results, no API dependency |
| sessionStorage for setlist tracking | Tab-scoped, auto-clears on close, no Zustand bloat | Simple, reliable session tracking |
| Hidden placeholder when no monitor | Maintains balanced 3-column layout without monitor access | Clean visual even for non-monitor users |
