<objective>
## Goal
Produce ONE triaged, severity-ranked findings report for the band's full path against the three
real upcoming Camp Sabra weekend sets — by (a) driving the deployed prod Perform surface with a live
Playwright sweep on real 11" iPad-WebKit (portrait + landscape, incl. a wifi-drop cell) and (b) running
a multi-agent read-only code audit of the reading / offline / publish code paths. **No production code
changes.** This report is the input that the v11.6-02/03/04 fix PLANs consume.

## Purpose
v11.6 is a narrow hardening milestone: the web app's job is the band/consumer surface, and "airtight"
must be proven by driving the *real* surface against *real* sets, not reasoned about. Two camp sets are
almost entirely `text/plain` (the less-hardened `TextScoreViewer` path) and the weekend is off-site
(camp wifi may break the "venue has wifi" assumption that justified dropping PWA offline). This phase
generates the evidence; it BLOCKS the three fix phases.

## Output
- `e2e/v11-6-perform-stress.spec.ts` — a re-runnable Playwright spec (the stress "cells").
- Per-cell artifacts (screenshots + console/network logs) under the Playwright output dir.
- `.paul/research/v11-6-01-stress-triage-REPORT-2026-06-17.md` — the triaged findings report.
