<objective>
## Goal
Ensure the real-time receiver experience is complete: when a swap occurs, musicians' performance views update seamlessly — the setlist refreshes, the correct chart loads, and an offline indicator warns if connectivity is lost. Then push everything to main for Vercel deployment.

## Purpose
The core swap flow (Phases 1-2) is built, but the receiver side needs polish for production reliability. Musicians on tablets during a live service need to trust that their view is current. This phase closes the loop and deploys.

## Output
- Offline connectivity indicator in performance view
- Verified chart reload when swapped track is being viewed
- All v3.0 code pushed to main on Vercel
</objective>
