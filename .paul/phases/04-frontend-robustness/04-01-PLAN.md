<objective>
## Goal
Fix hook dependency array bugs, add async unmount safety, fix the annotation store memory leak, and add ref counting to the monitor connection singleton.

## Purpose
Stale closures cause incorrect data rendering in live performance. Async operations on unmounted components cause React warnings and memory leaks in long sessions. The annotation store timer and monitor connection singleton leak resources across re-renders and auth cycles.

## Output
- All 8 hooks with corrected dependency arrays
- AbortController/isMounted patterns on all async hooks
- Annotation store timer tied to lifecycle
- Monitor connection with ref counting
</objective>

## AC-1: Hook Dependency Arrays Are Correct
```gherkin
Given hooks with dependency arrays
When the dependencies change
Then effects re-run only when semantically meaningful values change
And no circular dependencies exist between callbacks and effects
And no object/array references cause infinite re-render loops
```

## AC-2: Async Operations Are Unmount-Safe
```gherkin
Given a component with async operations (AI scan, Firestore fetch, API call)
When the component unmounts before the operation completes
Then no state updates occur on the unmounted component
And any in-flight requests are cancelled via AbortController where possible
```

## AC-3: Annotation Store Timer Is Lifecycle-Bound
```gherkin
Given the annotation store debounce timer
When the store is no longer in use (component unmounts)
Then the timer is cleared and no stale saves fire
And the module-level timer does not leak across store instances
```

## AC-4: Monitor Connection Has Ref Counting
```gherkin
Given multiple components using useMonitorConnection
When one component unmounts
Then the connection stays active for remaining consumers
And when the last consumer unmounts, the connection tears down
And when a new consumer mounts after teardown, it reconnects
```
