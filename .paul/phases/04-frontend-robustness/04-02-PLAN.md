<objective>
## Goal
Add error boundaries to crash-prone admin/setlist components, fix the root `useSafeFirestoreSync` type signature so callers don't need `ref as any`, and eliminate dangerous type assertions across hooks.

## Purpose
Admin pages with Firestore real-time subscriptions can crash from bad data shapes (SoundSystemSection, AccessAuditLog, LiveServiceSection). Without error boundaries, one section crash takes down the entire page. Meanwhile, 15+ `as any` casts across hooks hide type mismatches that could cause runtime bugs during live performance.

## Output
- 3 components wrapped with SectionErrorBoundary
- useSafeFirestoreSync accepts broader ref types without `as any`
- Dangerous `{} as unknown as Setlist` and `templateType as any` patterns replaced with proper types
- BridgeStatus.lastSeen typed properly for Firestore timestamps
</objective>
