<objective>
## Goal
Add the SwapToast receiver notification so musicians see when a song is swapped. The toast appears briefly (4s) when liveState.lastSwap changes, showing what was swapped. The director (who initiated the swap) does NOT see the toast.

## Purpose
When the music director swaps a song, all musicians need to know what changed. The SwapToast provides a non-disruptive notification that auto-dismisses, keeping musicians informed without interrupting their playing.

## Output
- SwapToast component (auto-dismissing 4s notification)
- Integrated into SetlistPerformPage, reading liveState from existing hook
</objective>
