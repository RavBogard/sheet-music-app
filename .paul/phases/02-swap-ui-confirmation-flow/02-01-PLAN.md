<objective>
## Goal
Add the swap button and bottom sheet picker to the performance view, enabling the 3-tap live swap flow: tap swap icon → pick alternative → "Swap Now". This is the director-facing swap initiation UI.

## Purpose
The music director needs to swap songs mid-service with minimal taps. This plan adds the visual swap trigger (SwapButton on eligible SetlistRows) and the selection UI (SwapBottomSheet with grouped alternatives), completing the director's swap flow.

## Output
- SwapButton component (amber ArrowLeftRight icon on eligible rows)
- SwapBottomSheet component (bottom sheet with alternatives + "Swap Now")
- SetlistRow extended with swap props
- SetlistView passes swap context to rows
- SetlistPerformPage wires swap state and swapLiveTrack() call
- useSetlistPerformance exposes liveState and setlistId for swap
</objective>
