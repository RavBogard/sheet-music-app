<objective>
## Goal
Make `library_index/{fileId}` and `songs/{fileId}` continuously consistent across devices. Two halves: (a) write-side parity — rename + archive routes mirror their effects to the songs/* doc; (b) read-side continuity — replace the one-shot `primeSongsLibrary` getDocs with a `subscribeSongsLibrary` snapshot listener so a song uploaded/renamed/archived on Daniel's iPad shows up live in the picker on his Mac without a manual refresh.

## Purpose
Closes the cross-device library-staleness gap explicitly deferred at v53-02-01 ("Cross-device freshness is deferred to v5.4 per Harness Fidelity Gate waiver in v53-02-01-PLAN.md"). Two concrete user-visible bugs go away: (1) renaming a song in the Library section doesn't update its title in the ChartBindPopover/AddRowPlaceholder picker until the user reloads; (2) archiving a song in Library doesn't remove it from the picker at all. With both halves shipped, the picker reflects the library's current state automatically — no F5, no second-device blindness — making the Daniel-on-Mac / band-on-iPad collaboration model viable for v6.0 production.

## Output
- New `src/lib/songs/subscribe.ts`: `subscribeSongsLibrary(opts)` snapshot-listener helper that mirrors Firestore `songs/*` → Dexie `songs` table; mounts once at app boot via SetlistGridHydrator (existing single-mount anchor); fail-soft same posture as `primeSongsLibrary`.
- `src/lib/songs/prime.ts`: deprecated comment + retained for test compatibility; call sites flipped to `subscribeSongsLibrary`.
- `src/app/api/library/rename/route.ts`: extends the rename atomic to also `db.collection('songs').doc(fileId).set({ title, normalizedTitle, updatedAt }, { merge: true })`.
- `src/app/api/library/archive/route.ts`: mirrors `status` field to `songs/{fileId}` so the picker can filter.
- `src/app/api/library/upload/route.ts`: stamps `status: 'active'` on the seeded `songs/{fileId}` doc (uniformity with archive).
- ChartBindPopover / AddRowPlaceholder picker queries: filter `status !== 'archived'` (treats missing status as active for backward compat with pre-v60-09 docs).
- Emulator-backed test `src/lib/songs/__tests__/subscribe.emulator.test.ts` proving listener round-trip (write → snapshot → Dexie put) and unsubscribe lifecycle.
- Expected delta: ~+200 LOC net (snapshot listener + 3 route edits + filter + tests).
</objective>
