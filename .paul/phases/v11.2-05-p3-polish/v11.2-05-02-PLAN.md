<objective>
## Goal
BUG-8: normalize ALL Firestore timestamps to ISO strings at the single MCP
response boundary (`jsonResult`), so no tool ever leaks a raw
`{_seconds,_nanoseconds}` Timestamp to the client.

## Purpose
The BL stress-test found `add_track_to_setlist` returns `updatedAt` as a raw
Firestore `{_seconds,_nanoseconds}` object while sibling fields
(`lastModifiedAt`, `get_setlist`) are ISO — an inconsistent, hard-to-consume
contract for Daniel's Claude Desktop authoring. A single boundary pass fixes
add_track AND any other tool with the same latent leak, uniformly.

## Output
- `src/lib/mcp/serialize-timestamps.ts` — pure deep-normalizer + unit tests.
- `jsonResult` applies it before `JSON.stringify`, so every tool response is ISO.
