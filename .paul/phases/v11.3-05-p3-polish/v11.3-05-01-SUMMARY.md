## Accomplishments

- **BUG-6 closed:** `src/proxy.ts` `config.matcher` token `manifest.json` → `manifest(?:-[a-z0-9-]+)?\.json`, so the per-org PWA manifest (`manifest-brotherslazaroff.json`, emitted by `layout.tsx`→`branding.ts`) bypasses the proxy exactly like the CRC default instead of 307→/login (HTML app shell). PWA install on broslaz is unblocked.
- **F-6 closed:** new `telemetry` rate-limit tier (300/min, IP-keyed) added to `rate-limit.ts`; `/api/auth/qr` (POST/GET/PUT) + `/api/web-vitals` repointed from `api`→`telemetry`. The 6-iPad-behind-one-NAT cold-load burst (~216/min combined) no longer exhausts the shared 60/min `api` bucket. Mirrors the ratified `chart`-tier NAT rationale.
- **Side benefit:** stops cold-cohort `/api/web-vitals` beacons from being 429-dropped → the v11.3-04-03 deferred RUM TTFB probe now captures the cold slice it needs.
- Regression coverage added to existing test files (no new test files): 5 matcher-regex cases (BUG-6) + 3 tier cases (F-6), each citing its stress finding.
