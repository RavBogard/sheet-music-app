# SUMMARY — v11.3-01-02 (BUG-4: anon transpose / AI chord-scan)

## What was built
Opened the two endpoints the anon transpose flow needs, per ACCESS-POLICY v0.3 **D-Q2**:
- `src/app/api/library/chord-cache/route.ts` — **GET** + **POST** now `requireAuth:false`
  (anon reads cached chord positions + meta; anon persists scan results so the next visitor
  gets a cache hit). `api` rate-limit kept. **PATCH** (`role:'musician'`) + **DELETE**
  (`role:'band_leader'`) unchanged.
- `src/app/api/ai/transposer/scan/route.ts` — POST now `requireAuth:false` with an
  **anon-only** `ai`-tier rate-limit: `if (!ctx.auth) { checkRateLimit(req,'ai') }`. The
  endpoint had NO rate limit before, so authed transpose is byte-identical (no regression).
- Regression tests: `scan/route.test.ts` (3) + `chord-cache/route.test.ts` (4).
- **No client edit** — `apiFetch` already sends anon (no token); the "Waiting for scan…"
  dead-end was purely the 401s and clears once the endpoints return 200.

## Verify-first / grounding
- Root cause (code + prod-corroborated 2026-06-10): anon GET `/api/library/chord-cache` → 401;
  anon POST `/api/ai/transposer/scan` → 401 — both `createApiHandler` default-auth. Scan had
  zero rate limiting. Client `use-smart-transposer.ts` stalls on "Waiting for scan…" when the
  scan 401s; `chord-cache.ts` `loadChordCache` returns null on the 401 → "no cache" → scan → 401.

## Decisions made
| Decision | Rationale | Impact |
|----------|-----------|--------|
| Open chord-cache **POST** to anon (not just GET) | Persisting an anon scan means the NEXT visitor gets a cache hit → fewer total Gemini scans — the cost-control intent of D-Q2's "rate-limit anon AI-scan". Benign derived data, rate-limited, leader-overwritable, `chordsVerified` stays leader-gated. | Lower AI spend; minor, mitigated cache-integrity surface. |
| Rate-limit scan for **anon only** (`if (!ctx.auth)`) | Authed transpose was unlimited; gating only anon = zero authed regression + abuse protection where it's needed. | Authed path byte-identical. |
| No client change | The dead-end was the 401s; `apiFetch` sends anon and the flow proceeds on 200. | Minimal surface. |
