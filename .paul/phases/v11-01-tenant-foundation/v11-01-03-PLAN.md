<objective>
## Goal
Stamp `orgId="crc"` on EVERY existing doc that lacks it across the five tenant-scoped
collections (setlists, tracks, library_index, songs, recordings), and seed the `orgs/{orgId}`
collection (`orgs/crc` + `orgs/brotherslazaroff`) from the ORGS registry. Idempotent,
dry-run-first, with a prod runner + RUNBOOK.

## Purpose
This is the SECOND precondition (paired with v11-01-02's write-path stamping) for safely
deploying strict org-scoped Firestore rules in v11-01-04. Rules can only `require` orgId once
(a) new writes emit it (v11-01-02 ✓) AND (b) all existing data carries it (this plan).
Without the backfill, a strict rule would reject every read/write of a legacy CRC doc →
service lock-out. All existing data is CRC, so the backfill is a uniform `orgId="crc"` stamp;
brotherslazaroff has no data yet (its org doc is seeded for v11-03 host routing).

## Output
A tested backfill+seed module, an emulator test proving it, and a prod `.mjs` runner +
RUNBOOK following the established `scripts/backfill-drive-id-on-library-index.mjs` pattern.
</objective>

## Key design decisions (baked in — engineering calls within ratified scope)
- **Pattern:** a one-time migration via the `.mjs` script + RUNBOOK convention
  (`scripts/backfill-drive-id-on-library-index.mjs` is the exemplar — .env.local loader,
  `cert()` admin init, DRY-RUN default, `--apply` flag, per-record stderr trace + JSON
  summary). NOT a permanent MCP tool — this stamps a fixed historical population once.
- **Testable core:** the scan/stamp/seed logic lives in a TS module
  (`src/lib/org/backfill-orgid.ts`) taking an injected `db`, so it gets emulator coverage.
  The `.mjs` runner is the thin prod wrapper.
- **Uniform "crc":** every doc missing orgId is stamped `DEFAULT_ORG_ID` ("crc") — all
  existing data is CRC. No per-doc tenant inference needed.
- **Idempotent:** a doc that already carries a non-empty `orgId` is skipped (never
  overwritten); a second run stamps 0. Firestore can't query "field absent", so the scan
  filters in memory (mirrors backfill_track_mimetype).
- **Org seeding via merge-set:** `orgs/{id}` gets `{id, name, domain}` from the ORGS
  registry; `createdAt` is stamped only when absent (re-run preserves the original).
</context>
