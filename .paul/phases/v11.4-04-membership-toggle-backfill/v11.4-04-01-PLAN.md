<objective>
## Goal
Extend the existing admin "Band access" tri-state control (CRC only / Brothers Lazaroff only /
Both) from leader-only rows to **every non-pending person** (musicians + members + leaders), so an
admin can set ANY person's org membership from /manage → People. This is the UI half of D8 item 5;
the default-both rollout (new-account default + backfill of existing people) is Plan 02.

## Purpose
Per Daniel's 2026-06-11 ratification, org membership applies to EVERYONE (incl. leaders → cross-
tenant authoring; musicians → cross-tenant publish-audience candidacy). The control + the
claim+doc lockstep already exist (v11.1-02-02) but are gated to the authoring tier; this opens it
to all roles so membership is admin-manageable per person before/after the Plan 02 backfill. Safe
now that v11.4-01 killed auto-blast (default-both can't cause a BUG-9 blast).

## Output
- `UserRow.tsx`: Band-access control + membership badge shown for all non-pending rows (admin-only),
  with copy generalized beyond "authoring" (it governs authoring for leaders, notifications/audience
  for musicians/members).
- A `UserRow.test.tsx` proving the control shows for a musician row and posts both orgIds.
</objective>
