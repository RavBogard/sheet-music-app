<task type="auto">
  <name>Task 1: CSP Directive Audit and Tightening</name>
  <files>next.config.ts</files>
  <action>
    Audit every CSP directive in next.config.ts against actual runtime needs:
    - Verify connect-src covers all Firebase, Google, and Sentry domains used at runtime
    - Check if any wildcard (e.g., *.googleapis.com) can be narrowed to specific subdomains
    - Verify frame-src covers accounts.google.com and *.firebaseapp.com (for popup)
    - Confirm script-src includes apis.google.com (needed for Google Identity Services)
    - Verify img-src covers lh3.googleusercontent.com (profile pics)
    - Check for any domains used at runtime but not in CSP (search source for fetch/XHR targets)
    - Remove any domains no longer needed
    - Add CSP report comments documenting why each domain is included
  </action>
  <verify>npm run build succeeds; grep the CSP string to confirm all expected domains are present</verify>
  <done>AC-1 satisfied: All CSP directives verified against runtime needs</done>
</task>

<task type="auto">
  <name>Task 2: Add Static PWA Icon Fallbacks</name>
  <files>public/manifest.json, public/icon-512.png, public/icon-192.png</files>
  <action>
    The dynamic /icon route works for browser favicon but may not serve reliably in all PWA install contexts (e.g., Android Chrome "Add to Home Screen" fetches manifest icons at install time).

    1. Generate static icon PNGs by fetching the /icon dynamic route during build, OR create simple static PNG files that match the dynamic icon's design
    2. Add 192x192 and 512x512 static icons to public/
    3. Update manifest.json to reference static files:
       - { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any" }
       - { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" }
    4. Keep the dynamic /icon route (it serves favicon and Open Graph)
  </action>
  <verify>ls public/icon-*.png confirms files exist; manifest.json references them; npm run build succeeds</verify>
  <done>AC-2 satisfied: Static icon fallbacks exist and manifest references them</done>
</task>
