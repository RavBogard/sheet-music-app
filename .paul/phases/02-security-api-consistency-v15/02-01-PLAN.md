<task type="auto">
  <name>Task 1: Add CSP, HSTS, and Permissions-Policy headers</name>
  <files>next.config.ts</files>
  <action>
    In the `headers()` function in next.config.ts, add three new headers to the existing array in the `/(.*)`source block:

    **Content-Security-Policy:**
    ```
    default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval' https://apis.google.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: blob: https://*.googleapis.com https://*.firebasestorage.app https://*.googleusercontent.com; connect-src 'self' https://*.googleapis.com https://*.firebaseio.com https://*.firebasestorage.app https://firestore.googleapis.com wss://*.firebaseio.com https://generativelanguage.googleapis.com; frame-src 'self' https://accounts.google.com; worker-src 'self' blob:; manifest-src 'self'; media-src 'self' blob: https://*.firebasestorage.app
    ```
    Note: `unsafe-inline` and `unsafe-eval` are needed for Next.js. This CSP still provides XSS protection by restricting script sources to known domains.

    **Strict-Transport-Security:**
    ```
    max-age=31536000; includeSubDomains
    ```
    Vercel already enables HSTS but this makes it explicit and sets a long max-age.

    **Permissions-Policy:**
    ```
    camera=(), microphone=(self), geolocation=(), payment=()
    ```
    Disable unused browser features. Microphone allowed for potential future audio features.

    Keep all existing headers in place. Just add the three new entries to the headers array.
  </action>
  <verify>
    1. `npx tsc --noEmit` passes
    2. `npx next build 2>&1 | tail -5` — build succeeds
    3. Grep confirms headers present: `grep -c 'Content-Security-Policy\|Strict-Transport-Security\|Permissions-Policy' next.config.ts` — shows 3
  </verify>
  <done>AC-1 satisfied: All three security headers configured</done>
</task>
