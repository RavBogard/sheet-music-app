<objective>
## Goal
Fix silent failure patterns: add logging to empty catch blocks, add logging to fire-and-forget notification tracking updates, and move hardcoded CORS domains to environment-only configuration.

## Purpose
Silent failures hide bugs from operators. When notification delivery tracking silently fails, musicians may not know if their assignment emails went through. When CORS domains are hardcoded, a domain change requires code changes instead of config updates.

## Output
All modified files pass `npx tsc --noEmit` with zero new errors. No empty catch blocks remain in targeted files. All domain references derive from environment variables.
</objective>
