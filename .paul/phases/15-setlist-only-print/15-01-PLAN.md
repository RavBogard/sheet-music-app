<objective>
## Goal
Add a "Setlist Only" print option that generates just the cover page (song list with keys, BPM, lead) without any chart PDFs.

## Purpose
Musicians often need a quick one-page song list for the music stand. Currently printing always bundles the cover page with all chart PDFs, which is slow and wastes paper when only the song list is needed.

## Output
- Modified PrintModal with a toggle between "Full Packet" and "Setlist Only"
- Modified print pipeline that skips PDF fetch/merge when coverOnly is true
- Updated API route to accept coverOnly parameter
</objective>
