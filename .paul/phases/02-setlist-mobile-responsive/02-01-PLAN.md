<objective>
## Goal
Fix squashed/overflowing setlist views on mobile phones by replacing fixed widths and padding with responsive values, stacking toolbar controls on narrow screens, and making card actions touch-accessible.

## Purpose
Setlist management is the core workflow. If it's unusable on phones, musicians can't manage setlists from their devices during prep. The current layout was designed desktop-first with fixed widths and padding that break below ~768px.

## Output
- All 4 setlist components responsive from 375px to 1536px
- Toolbar stacks on mobile, inline on tablet+
- Cards use responsive padding and don't truncate titles aggressively
- Touch-friendly action menus (always visible on mobile, hover-reveal on desktop)
</objective>

## UI/UX Guidelines Applied (from /ui-ux-pro-max)
- Mobile-first: default mobile styles + md:/lg: breakpoints
- Responsive padding: px-4 md:px-6 lg:px-8
- Touch targets: min 44px on mobile
- No horizontal scroll (except intentional matrix)
- Hover-only UI must have touch fallback (overflow menus)
