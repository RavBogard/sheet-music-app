- **Both user-facing mint paths** now read the proxy-resolved `x-org-id` (host org) and pass it through `resolveMintOrg`:
  - `src/app/api/mcp/oauth/token/route.ts` (the path Claude Desktop's OAuth uses) — `coerceOrgId(req.headers.get("x-org-id"))`.
  - `src/app/api/mcp/tokens/route.ts` (self-service) — `coerceOrgId(ctx.req.headers.get("x-org-id"))`.
- Org is pinned at **mint time from the host**, never from a tool/body arg → the v11-06-02 no-arg-injection invariant is fully preserved (that test is unchanged and green).
- No escalation: a user can never mint for an org outside their `orgIds` (a crc-only user on the broslaz host still mints crc).
