## Deviations

- **Test is a mocked unit test, not an emulator test** (plan said emulator). The repo's admin routes are unit-tested with firebase-admin mocked (pattern: `sync-claims/__tests__/route.test.ts`); the emulator suite is for data-layer/rules. The unit test exercises the exact new branches (doc orgIds write, claim spread, validation, admin gate) faster and matches convention. Justified, no coverage loss.
- **PeopleSection NOT modified** (plan listed it "if needed"). UserRow already receives `currentUserRole`, from which `isCurrentAdmin` is derived (already powers the admin-only delete button) — no extra threading required. Minimal footprint.
- Self-edit allowed for the membership control (role control hides for self): all three options are non-empty so there's no lockout, and an admin may legitimately set their own "Both". Confirm dialog covers intent.
