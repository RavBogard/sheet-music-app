<objective>
## Goal
Fix the one unambiguous chord-spelling bug from the text-chart triage: a
transposed **slash-chord bass note** is spelled with the ROOT's flat/sharp
scale choice rather than its own, so when the root resolves to the sharp
scale a bass landing on pitch-class 10 or 3 renders the never-used `A#`/`D#`
instead of the conventional `Bb`/`Eb` (WS-25). Example: `transposeChord('F/A', 1)`
yields `F#/A#` today; it should be `F#/Bb`.

## Purpose
Transpose is a first-class authoring/Perform action (musicXML + text charts),
and `transposeChord` is the shared engine. `A#`/`D#` as a bass root is
essentially never written; a musician reading `F#/A#` off an iPad sees a
spelling no chart would print. This tightens spelling correctness without
touching the (correct) key-context behavior that produces e.g. `G/B`→`A/C#`.

## Output
- `src/lib/music-math.ts`: the slash-bass branch recomputes flat/sharp via
  `shouldUseFlats(newBassIndex, bassAccidental, useFlats)` — passing the
  root's choice as the `preferFlats` hint so the bass follows the chord's key
  context EXCEPT the always-flat overrides (10→Bb, 3→Eb).
- `src/lib/music-math.test.ts`: WS-25 cases + locked-in regression cases
  proving existing slash spellings are unchanged.

## Scope note (deliberate deferrals — baked into this plan)
The other three text-chart nits are DEFERRED to v11.7 polish, not fixed here:
- **WS-19** (chord-line regex false-positive, P2): "A E" is genuinely valid
  as two chords; any heuristic tweak risks demoting real sparse chord/intro
  lines — a worse failure than the cosmetic mis-stack. Defer.
- **WS-23** (preferFlats hardwired undefined, P3): would require an
  `estimateKey` heuristic that can MISFIRE and flip spelling on the live camp
  fixtures; the current source-convention-preserving default is safer. Defer.
- **WS-24** (section-gap collapse, P3): not reproducible from the parser
  (blank lines render as a 1.5em text-only gap). No repro → no fix; needs a
  concrete sample chart first. Defer.
This keeps the airtight milestone fixing real defects, not churning cosmetics.

  transposeChord('F/A', 1) === 'F#/Bb'  (not 'F#/A#')
