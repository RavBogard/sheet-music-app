# Phase v11.6-02.1 Plan 01: Gig-packet text charts (P0)

**The website Gig Packet now renders scraped `text/plain` chord charts (Courier monospace, chord-over-lyric, transpose-aware) instead of silently dropping them — David's Camp Sabra sets (all/mostly text) printed as a chartless cover page; root cause was the print pipeline only handling PDF + image charts.**

## P0 — live-service issue
David reported gig packets failing on centralreform.live. **Data-confirmed diagnosis** (not a guess): `verify_setlist_charts` showed Camp Sabra Staff Concert = 14/14 bonded charts `mimeType: text/plain` (all reachable), vs. Shir Shabbat—Juneteenth = 14/14 `application/pdf` (prints fine). The web pipeline `PDFDocument.load`s every chart; text bytes throw → caught at `print-pipeline.ts:836` → chart skipped. Vercel logs corroborated: every `/api/setlist/print` was 200 (no crash) with error-level "PDF parse error" lines on the text-set runs. Latent format gap (print never learned the scraped-text format Perform renders on iPads), newly hit by all-text camp sets.
