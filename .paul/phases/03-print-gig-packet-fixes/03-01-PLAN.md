<objective>
## Goal
Fix three bugs in the print gig packet feature: (1) black screen overlay when printing, (2) wrong date (uses today instead of eventDate), (3) 401 auth error from silent token failures.

## Purpose
Print gig packet is broken for live use — musicians can't reliably print their transposed charts for services.

## Output
- Print uses iframe instead of window.open to avoid black screen
- Date defaults to setlist eventDate when available
- apiFetch retries token on failure instead of silently proceeding unauthenticated
</objective>


```gherkin

```

  <name>Task 1: Fix black screen with iframe-based printing</name>
  <files>src/components/setlist/PrintModal.tsx</files>
  <action>
    In PrintModal.tsx, replace the window.open approach (lines 332-334) with iframe-based printing:

    Replace:
    ```
    const printWindow = window.open(url)
    if (printWindow) { printWindow.onload = () => printWindow.print() }
    ```

    With logic that:
    1. Creates a hidden iframe element
    2. Sets iframe src to the blob URL
    3. On iframe load, calls iframe.contentWindow.print()
    4. Removes the iframe after a short delay (to allow print dialog to appear)
    5. Revokes the blob URL after cleanup

    This avoids the black screen caused by window.open on blob URLs in modern browsers.
  </action>
  <verify>
    - npx tsc --noEmit passes
    - Print path uses iframe instead of window.open
    - Blob URL is cleaned up after printing
  </verify>

  <files>src/lib/api-client.ts</files>
  <action>
    In apiFetch, change the token retrieval to retry on failure:

    1. First attempt: `user.getIdToken()` (uses cached token)
    2. If that throws, retry with `user.getIdToken(true)` (force refresh)
    3. If retry also throws, throw an error: "Authentication expired. Please sign in again."
    4. Do NOT silently proceed without auth — the current silent catch causes 401s

    Keep the case where `user` is null (no user signed in) as-is — some routes may be public.
  </action>
  <verify>
    - npx tsc --noEmit passes
    - apiFetch retries token on first failure
    - Throws clear error if both attempts fail
    - Still works when no user is signed in
  </verify>
