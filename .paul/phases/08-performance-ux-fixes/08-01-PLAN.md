<objective>
## Goal
Fix three performance UX issues: (a) relabel toolbar buttons to match musician terminology, (b) fix the broken setlist drawer that shows blank content, (c) add monitor mix access from the setlist perform view.

## Purpose
Musicians need clear, space-efficient labels and working controls during live performance. "Audio" is vague — musicians call it "Monitor." "Metronome" wastes space — "BPM" is universally understood. The setlist drawer is broken (blank content), and monitor mix controls should be accessible from the setlist view, not just the chart view.

## Output
- PerformanceToolbar: "Audio" → "Monitor", metronome label → "BPM"
- SetlistDrawerLegacy: fix blank content (ScrollArea/virtualizer conflict)
- Setlist perform page: add monitor mix button in header
</objective>

<task type="auto">
  <name>Task 2: Fix blank setlist drawer (ScrollArea/virtualizer conflict)</name>
  <files>
    src/components/performance/SetlistDrawerLegacy.tsx
  </files>
  <action>
    **Root cause:** The SetlistDrawerLegacy wraps content in a shadcn `ScrollArea` component, but also has a nested `div.flex-1.overflow-auto` with `ref={parentRef}` for TanStack Virtual's `getScrollElement`. Radix ScrollArea creates its own scroll viewport that intercepts scrolling, so the virtualizer's parentRef never receives scroll events → virtualizer calculates zero visible rows → blank content.

    **Fix:** Replace the `ScrollArea` wrapper with a plain `div` and let the virtualizer's `parentRef` div handle scrolling natively.

    Specifically:
    1. Remove the `ScrollArea` import
    2. Replace `<ScrollArea className="flex-1 h-full bg-background">` with `<div className="flex-1 overflow-hidden bg-background">`
    3. Close with `</div>` instead of `</ScrollArea>`
    4. The inner `parentRef` div with `overflow-auto` remains as-is — it becomes the sole scroll container
    5. Ensure the parentRef div has proper height constraint (e.g., `h-full` or `min-h-0` for flex sizing)

    **Do NOT change:**
    - The virtualizer configuration
    - The track rendering logic
    - The public setlist picker (non-virtualizer path)
    - Key badges or any display logic
  </action>
  <verify>cd sheet-music-app && npx tsc --noEmit</verify>
