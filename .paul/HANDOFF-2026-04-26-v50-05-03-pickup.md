### Scope (per ARCHITECTURE.md §6.6/6.7/6.11/6.13)

**§6.6 — Multi-select / batch edit**
- Shift-click row range; Cmd/Ctrl-click toggle; arrow-key range extension.
- Bulk Backspace delete (with one combined `confirmDeleteWithTitle` prompt or AlertDialog if shipped together — see below).
- Sticky batch-edit toolbar at bottom: "N rows selected" + Key / Lead / BPM / Type bulk-set Popover triggers.
- Bulk-set fires N applyEdit calls in parallel (engine handles ordering).

**§6.7 — iPad/touch variant (≥768px touch device)**
- Cell dropdowns swap from Radix Popover → Radix Sheet (bottom sheet) when `(pointer: coarse)` matches.
- 44px touch targets minimum (most cells already at 40px — bump padding).
- Hover-only affordances (drag-handle reveal on row hover, etc.) become always-visible OR get long-press equivalents.
- Drag-handle column wider (52px instead of 44px) for tap accuracy.

**§6.11 — Mobile-only stacked-card flow (<768px)**
- Drop the table layout entirely below 768px.
- Render rows as stacked cards with primary fields visible (title + key + lead).
- Tap card → full-screen sheet with all-fields edit pane.
- Reorder via long-press + drag (or up/down buttons inside the sheet).

**§6.13 — WCAG AA binding accessibility verification**
- Run axe-core / Lighthouse against `/setlists/{some-id}` on prod.
- Fix focus-trap gaps in popovers (Radix usually handles this, but verify cmdk inside Popover.Content).
- Verify keyboard-only navigation across all cells + add-row + chart-bind + delete (no mouse-only paths).
- Verify aria-live announcements for SyncIndicator state changes (already wired per v50-05-01; verify timing).
- Verify color contrast ratio ≥ 4.5:1 for SyncIndicator state colors (failed = red; conflict = amber; offline = gray).

**AlertDialog swap-in for window.confirm**
- The `confirmDeleteWithTitle` injection point is already in SetlistGrid props (per v50-05-01). Default still `window.confirm`.
- New AlertDialog wraps SetlistGrid when mounted from page.tsx; `confirmDeleteWithTitle={title => alertDialogPromise(title)}` swaps the prompt without touching call sites.
- Use Radix AlertDialog primitive (already in shadcn/ui? — verify; if not, install).

**Right-click ContextMenu on rows + drag handle**
- Radix ContextMenu primitive.
- Items: "Edit row" (focuses Title cell), "Bind chart" (opens ChartBindPopover programmatically), "Duplicate row", "Delete row".

**Undo via zustand temporal middleware**
- Wrap a small zustand store around the local Dexie writes.
- Intercept BEFORE applyEdit; record (op, collection, docId, prevDoc, newDoc) snapshot per undo unit.
- Cmd/Ctrl-Z replays the inverse via applyEdit.
- Coalesce burst edits (typing in a Title cell) into one undo unit per cell-blur.
- Store cap = 50 undo entries (or session-bounded; not persisted across reloads since Dexie is the persistence layer).
