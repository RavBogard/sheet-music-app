## What's Next: Plan v50-05-04 (iPad / pointer-coarse touch + ContextMenu)

**Second polish plan.** All scope items have been deferred from v50-05-01 through v50-05-03 with explicit injection points; no architectural decisions remain unresolved going in.

### Scope (per ARCHITECTURE.md §6.7)

**§6.7 — iPad / pointer-coarse touch variant**
- **Cell dropdowns swap from Radix Popover → Radix Sheet** when `useMediaQuery('(pointer: coarse)')` matches.
  - Affects: `KeyCell`, `LeadCell`, `TypeCell` (all via `DropdownCell` — single swap point covers three cells), `AddRowPlaceholder`, `ChartBindPopover`, AND the new v50-05-03 `BatchActionBar`'s inline `BulkPopover` helper.
  - Recommended pattern: extract a shared `<TouchOrPopover>` wrapper component that picks Radix Popover or Radix Sheet based on the media query — single integration point, reuses cmdk content as children.
  - **Touch detection keys on `(pointer: coarse)` media query, NOT viewport width.** iPad Pro at 1024px is still touch — viewport-based detection would miss it and over-trigger on resized desktop browsers.
- **44px minimum touch targets** — bump cell padding from 8px → 12px on touch breakpoints (`@media (pointer: coarse)`). Drag-handle button is already 44px (h-11 w-11) but column width is currently 44px — bump to 52px for tap accuracy with the visual handle still centered.
- **Hover-only affordances become always-visible OR get long-press equivalents** — no hover state means the chart-icon ghost / drag-handle reveal won't fire on touch. Make them always-visible at touch breakpoints; long-press (500ms hold) opens ContextMenu.
- Edit-mode cell shows a "Done" button in the bottom-right (commits and advances; replaces Tab gesture which is awkward on touch).

**Right-click ContextMenu (Radix `@radix-ui/react-context-menu`)**
- shadcn primitive `src/components/ui/context-menu.tsx` is already installed (verified in v50-05-03 ls).
- ContextMenu mounts on rows + drag handle.
- Items:
  - **Edit row** — focuses the Title cell (calls SetlistGrid's existing `handleCellFocus(rowIndex, 'title')`).
  - **Bind chart** — programmatically opens `ChartBindPopover` (need an imperative open handle; currently it's controlled by an internal `open` state — small refactor: lift open state to controllable via prop, OR add a `triggerKey` signal pattern matching `AddRowPlaceholder`'s autoOpen).
  - **Duplicate row** — clones the row's data via `applyEdit('set', 'tracks', { ...row, id: newId, order: row.order + 1 })` + reorder cascade.
  - **Delete row** — routes through the existing `confirmFn({kind:'row', title})` → `DeleteConfirmProvider` AlertDialog (or bulk delete if the right-clicked row is part of a multi-selection ≥ 2).
- ContextMenu is selection-aware: if the right-clicked row is in `selection.selectedIds`, actions target the whole selection (Delete becomes bulk); if not, actions target just that row.
- Long-press equivalent on touch: ContextMenu opens after 500ms hold (Radix supports this natively via `onPointerDown` timer pattern, OR via `useLongPress` if a hook needs adding).
