## Key Context

- The root cause of auth failures was a **vicious cycle**: old Service Worker served cached HTML with old CSP headers, which blocked Google auth domains in `connect-src`, preventing sign-in and preventing the new SW from activating
- `lh3.googleusercontent.com` is NOT covered by `*.googleapis.com` — it's under `google.com`
- `apis.google.com` is also NOT covered by `*.googleapis.com`
- User preferences: Google-only sign-in, never use local dev server, push everything to main
- User hates the tablet landscape sidebar toolbar — wants bottom toolbar on ALL viewports
