```typescript
// sendPushToUsers(targetUids: string[], notification: { title: string; body: string; link?: string })

```

Implementation (extract and adapt from /api/push/send/route.ts lines 56-147):
1. Import `initAdmin, getFirestore` from `@/lib/firebase-admin` and `logger` from `@/lib/logger`
2. Call `initAdmin()` at the top
3. Batch-read user docs (30 at a time) to collect `fcmTokens` arrays
4. If no tokens found, return `{ sent: 0, failed: 0, staleTokensCleaned: 0 }`
5. Build the message object with `notification: { title, body }` and `webpush: { fcmOptions: { link: process.env.NEXT_PUBLIC_BASE_URL + link } }` (only if link provided)
6. Send via `messaging.sendEachForMulticast` in batches of 500
7. Track stale tokens (error code `messaging/registration-token-not-registered`) and clean them up using `FieldValue.arrayRemove`
8. Return stats

This is essentially the logic from /api/push/send/route.ts but as a callable function instead of an API route. Do NOT duplicate -- extract the logic.
