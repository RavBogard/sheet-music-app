Extend `syncLibraryIndex()` in sync-engine.ts with the following phases. The current function already does steps 1-5 (list files, get existing docs, purge chord caches, batch write metadata, detect deletions). Add Storage copy AFTER the metadata batch write, and add sync run logging.

**Phase A: Identify files needing Storage copy (after step 3, before step 5)**
After building existingDocs map, also query for `storageCopiedAt` and `storageFailed` fields (add to the `.select()` call on line 45). Build three lists:
1. `newFilesCopy`: files not in existingDocs AND not folders -- need first-time copy
2. `failedRetryCopy`: files in existingDocs where `storageFailed === true` -- need retry
3. `modifiedCopy`: files in existingDocs where modifiedTime changed AND `storageCopiedAt` exists -- need refresh

Combine and limit to `MAX_COPIES_PER_RUN = 20`.

**Phase B: Copy files to Storage (after metadata batch write)**
For each file in the copy list:
1. Call `drive.getFile(file.id)` to get bytes (use the existing DriveClient instance)
2. Convert to Buffer, skip if `buffer.byteLength < 50`
3. Call `uploadToStorage(file.id, buffer, file.mimeType || 'application/pdf')` from firebase-storage.ts
4. On success: update Firestore doc with `{ storageCopiedAt: new Date().toISOString(), storageFailed: null, storageError: null }`
5. On failure: update Firestore doc with `{ storageFailed: true, storageError: err.message }`, add to errors array, increment copyErrors stat
6. Track stats: copiedToStorage, copyErrors, retriedCopies

Import `uploadToStorage` from `@/lib/firebase-storage` at top of file. Import `getStorage` from `firebase-admin/storage` is NOT needed -- firebase-storage.ts handles bucket access.

**Phase C: Delete Storage files for deleted Drive files**
For files detected as deleted (already in stats.deletedFiles), also delete from Storage. Use the Storage bucket to delete `library/${fileId}.pdf` and `library/${fileId}.xml` (try both, ignore not-found errors). Also delete the Firestore doc (currently only detected, not deleted). Track deletedFromStorage count.

For Storage deletion, import and use:

```typescript
import { getStorage } from 'firebase-admin/storage'

for (const ext of extensions) {
  await bucket.file(`library/${fileId}${ext}`).delete().catch(() => {})
}
```
