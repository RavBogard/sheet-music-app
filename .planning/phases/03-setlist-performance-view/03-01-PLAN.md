<objective>
Build the dense, scannable setlist performance view -- the core of Phase 3. Musician sees the full service flow at a glance on a portrait tablet: song titles in their transposed key, tempo, lead, and liturgical items -- all without tapping. Leader-driven position highlighting and wake lock keep the musician oriented during live services.

Purpose: This is the foundation for the entire performance experience. The PDF overlay (Plan 02) and public access (Plan 03) both build on this view.
Output: Redesigned `/perform/setlist/[id]` page with dense rows, auto-transposition, position highlighting, and wake lock.
</objective>

  <name>Task 1: Create SetlistRow component and useSetlistPerformance hook</name>
  <files>src/components/performance/SetlistRow.tsx, src/hooks/use-setlist-performance.ts</files>
  <action>
  Create two files:

  **SetlistRow.tsx** -- Dense row component per CONTEXT.md locked decisions:
  - Song rows: bold title (font-semibold text-base), transposed key badge (font-mono text-xs bg-muted rounded px-1.5 py-0.5), tempo (text-xs tabular-nums), lead musician (text-xs text-blue-400, truncated to ~60px).
  - Show just the transposed key name (e.g., "Bb"), not the semitone offset -- per RESEARCH.md recommendation.
  - Non-song items: quieter styling (text-sm text-muted-foreground), just the label, no timing/duration.
  - Notes hidden by default; tap the row to toggle notes visibility (per CONTEXT.md "Notes hidden until tapped").
  - Current position highlight: `bg-violet-500/15 border-l-2 border-violet-500` -- visible from arm's length.
  - Song rows with fileId are clickable (cursor-pointer); non-song items and songs without files are not.
  - Accept props: `track: SetlistTrack`, `index: number`, `isCurrentPosition: boolean`, `defaultTransposition: number`, `isPublicView: boolean`, `onSongTap: () => void`, `isLeader: boolean`, `onLeaderSetPosition: () => void`.
  - When isLeader is true, tapping ANY row (song or non-song) also calls onLeaderSetPosition to update current position.
  - Compute transposed key using `getTransposedKeyName(track.key, defaultTransposition)` -- only when not public view and defaultTransposition !== 0.
  - Use `cn()` from `@/lib/utils` for conditional classes.
  - Dark mode support via standard Tailwind dark: prefixes (already handled by muted-foreground, bg-muted, etc.).

  **useSetlistPerformance.ts** -- Orchestration hook:
  - Accepts `setlistId: string`.
  - Subscribes to setlist document via `useSafeFirestoreSync` (same pattern as existing page).
  - Extracts `tracks`, `name`, `serviceNotes`, `liveState` from the document.
  - Computes `currentTrackIndex` from `liveState.currentTrackIndex` when `liveState.enabled` is true, else -1.
  - Gets `defaultTransposition` from `useMusicianTransposition` hook (or profile -- check existing hook's return value).
  - Calls `useWakeLock().requestWakeLock()` on mount (in useEffect, triggered by user gesture of navigating to page).
  - Returns: `{ tracks, name, serviceNotes, loading, error, currentTrackIndex, defaultTransposition, isWakeLockActive }`.
  - Determines `isLeader` by checking if current user is admin or band_leader role (from `useAuth()`).
  - Returns `isLeader` and `setCurrentPosition(index)` which calls `updateLiveTrack`.
  </action>
