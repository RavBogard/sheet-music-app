    **1. Extend ChatEditAction** with key/tempo/position fields (EDIT-10):
    - Add `key?: string` and `bpm?: number` to ChatEditAction interface
    - Add `afterTitle?: string` field for positional insertion ("add X after Y")
    - In `use-setlist-logic.ts` handleApplyEdits: when processing 'add' action, apply key/bpm if present on the action. When `afterTitle` is set, find the track with that title and insert after it (instead of at end or at index).

    **2. Enhance /api/chat/route.ts** for template auto-fill (EDIT-09):
    - When AI detects a CREATE_SETLIST command with a template type (e.g., "Create a Daniel Friday for March 14"):
      a. Parse the template type from the message (map natural language to template key: "Daniel Friday" -> "friday_night" with rabbi="daniel_karen")
      b. Parse the target date from the message
      c. Import and call `getTemplate(serviceType)` to get the template
      d. Import and call `buildSetlistFromTemplate(template, libraryFiles, context)` to generate tracks
      e. Return the populated tracks as a CREATE_SETLIST response
    - The template auto-fill should use the same Fuse.js library matching as the manual template picker
    - Include the rabbi in the ServiceContext so onlyFor/skipFor filtering works

    **3. Update system prompt** in /api/chat/route.ts:
    - Add available template types to the system prompt so Gemini knows what templates exist
    - Add instruction: "When user asks to create a service, identify the template type and date, then use CREATE_SETLIST with template_type and date fields"
    - Add instruction: "When adding songs, you can specify key and bpm. When user says 'in Am', set key='Am'. When user says 'after the responsive reading', use afterTitle to position the track."

    **4. Extend chat-store.test.ts:**
    - Test that ChatEditAction with key/bpm fields is correctly structured

    - Test template type parsing: "Daniel Friday" -> friday_night + rabbi=daniel_karen, "Saturday Morning" -> shabbat_morning, "Rosh Hashanah Evening" -> rosh_hashanah_evening
