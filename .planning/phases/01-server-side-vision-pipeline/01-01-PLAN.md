  <name>Task 1: Create the Vision API Endpoint</name>
  <files>src/app/api/ai/transposer/scan/route.ts</files>
  <action>
    Create a new Next.js App Router POST endpoint at `/api/ai/transposer/scan/route.ts`.
    
    Implementation details:
    1. Parse the incoming request for a `base64Image` string.
    2. Initialize the `@google/generative-ai` SDK (`GoogleGenerativeAI`) using `process.env.GEMINI_API_KEY`.
    3. Use the `gemini-1.5-pro` model.
    4. Define a `responseSchema` enforcing an array of objects with properties: `text` (string), `x` (number), `y` (number), `w` (number), `h` (number). Set `responseMimeType` to `application/json`.
    5. The prompt MUST strictly instruct the model to:
       - Act as an expert transposer reading sheet music.
       - Extract every chord symbol on the page.
       - Return their bounding boxes as a PERCENTAGE (0 to 100) of the overall image width and height.
       - If no chords exist, return an empty array `[]`.
    6. Execute `generateContent` passing the base64 image (mimeType "image/jpeg" or "image/png").
    7. Parse the response text as JSON and return it via `NextResponse.json({ chords })`.
    8. Wrap in a try/catch block to return a 500 status on internal failures.
  </action>
  <verify>

  </verify>

    Endpoint compiles without type errors and maps the Gemini SDK correctly.
  </done>
