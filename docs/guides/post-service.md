# After every service — Michael's checklist

- [ ] Collect the six iPads. **Leave them signed in**, put them back on the cart and plug every one
      in.
- [ ] Count them: six iPads, six chargers.
- [ ] Ask Drew whether the recording is in Dropbox (a SERVICES folder named like `11.07_SAT MORNING`,
      MP3 ending in `_V1`).
- [ ] Shut down the **studio PC**: Start → Power → **Shut down**. Wedge mixes are already saved by
      then, and any bridge update installs during shutdown.
- [ ] Anything go wrong today? Text Daniel what happened, when, and which iPad (`CRC Band 3`).

Changes made "for tonight" (a swapped song or key) clear themselves after the service day. You
don't need to undo them.
