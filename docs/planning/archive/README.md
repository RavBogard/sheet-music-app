# docs/planning/archive

Finished planning documents kept for the record, not for reading top to bottom.
Two kinds of thing live here:

- **Pre-2026-09 plans, audits and reports** that used to sit loose at the repo
  root: the `AUDIT-*` series, the four `LIVING-SCORE-*` documents, the 2026-05
  bugfix and research plans, the code/TypeScript/UI review reports, and the
  workstream notes. They describe work that is done or superseded.
- **Evidence files** cited by a return, most notably
  `FIXTURE-PURGE-MANIFEST-2026-09-04.json` and
  `FIXTURE-PURGE-EVIDENCE-2026-09-04.json`, which
  `docs/planning/2026-09-04-green-repair/RETURN-CODE-LIVE-FIXTURE-PURGE-2026-09-04.md`
  refers to. They were moved here from the repo root by the 2026-09-19 audit
  (item (f)) rather than deleted, because a return that cites its evidence
  should still be able to find it.

Everything here is a record of what was true when it was written. Paths quoted
inside these documents are the paths of their own moment and are deliberately
not rewritten; if one no longer resolves, the file it names has usually moved
into `docs/planning/<date>-<topic>/` or into this directory.

Live work is in `docs/planning/<date>-<topic>/`. The current one is
`docs/planning/2026-09-19-audit/`.
